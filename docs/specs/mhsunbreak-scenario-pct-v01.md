## 1. 何をするか

BZシナリオの**候補の絞り込み（消去法）は現状維持**のまま、残った候補に
「参考％（設定1基準）」を添える。均等配分方式は採用しない（夢爽決定 2026/10/11）。

```
候補：A 62% ／ B 25% ／ D 13%
```

- 設定1否定が記録されているあいだは％を出さない（候補だけを出す）
- 順位・確定・推奨（続行／やめ）の表現は追加しない（§9-103）

## 3. 計算

### 3.1 対象

`scenarioCandidates(session)` で残った候補のみ。候補の作り方は**1行も変えていない**。

### 3.2 重み

候補 s の重みは

```
w(s) = P1(s) × Π_{k=1..min(n,7)} T( level(s,k), table_k )
```

- `k` は**ブレイクゾーン当選回数**（`start.prior + そのAT間で数えたBZ件数`）
- `table_k` は k 回目に記録したテーブル。`level(s,k)` は §2.3 の表
- **BZ以外の出来事（アイルー福引・アイキャッチ・チッチェのセリフ・サイドランプ）は重みに使わない。**
  アイキャッチ・セリフは従来どおり**消去法にだけ**使う
- **8回目以降のBZは重みに使わない**（`SCENARIO_MAX=7` と同じ扱い）
- 開始が「既にBZ n回」のときは、見ていない n 回ぶんの因子を掛けない
  （どのシナリオでも全テーブルの合計＝1 になるので、掛けないのが正しい）
- 候補として残っているシナリオでは、どの因子も必ず正（0 になる組合せは消去法で消えている）

### 3.3 ％

```
share(s) = w(s) / Σ w(候補) × 100
```

- 表示は**四捨五入した整数**。合計が100%にならなくてよい
- `share < 0.5%` の候補は **「1%未満」** と出し、候補からは消さない（夢爽決定 2026/10/11）。
  候補として残っているものを「0%」と出すと「あり得ない」と読めてしまうため（§2-1）
- 区切りは全角スラッシュ。`A 62% ／ B 25% ／ D 13%`
- **％を出しているときの見出しは `候補（％は設定1の場合）：`**（夢爽決定 2026/10/11）。
  ％を出さないときは従来どおり `候補：`。見出しと本文は `candHead(pct)` / `candBody(candidates,pct)` の
  1か所に置き、画面（現在の状況・過去のAT間）とBZシナリオカードで同じものを使う

### 3.4 ％を出さない条件（候補表示は従来どおり）

| # | 条件 | 画面 |
|---|---|---|
| a | 開始不明（`start.known===false`） | `BZ番号が不明のため絞り込めません` |
| b | 候補0件 | `該当なし：開始の選び方・記録を確認してください` |
| c | 設定1否定あり | `候補：A・B・…`（％なし） |
| d | 候補1件 | `シナリオ○濃厚`／`シナリオH濃厚：3回目のBZでAT濃厚` |

#### c. 設定1否定の判定

**既存の記録から導く。新しい入力項目は作らない。**
`allCert(S)` が持つ `rank`（濃厚の下限設定）が **2以上**の項目が1件でもあれば非表示。
記録全体（AT間をまたいだ全記録）に対して判定するので、**全AT間で同じ扱い**になる。

対象18項目：

| 分類 | 項目 |
|---|---|
| エンタトロフィー | 銅(2以上)・銀(3以上)・金(4以上)・紅葉柄(5以上)・虹(6) |
| エンディング中スタンプ | 銅・銀・金・紅葉柄・虹（同じ下限） |
| AT終了画面 | ヒノエ＆ミノト(2以上)・全員集合(5以上)・エンタライオン(6) |
| 獲得枚数表示 | 222枚 OVER(2以上)・**246枚 OVER(設定2・4・6濃厚)**・456枚 OVER・555枚 OVER・666枚 OVER |

対象外（設定1を否定しないので％は出したまま）：奇数／偶数設定期待度UP、高設定期待度UP(弱)(強)、
**設定2否定・設定3否定**、エンディング中スタンプの青・黄・緑・赤。

## 4. 表示

| 場所 | 出すもの |
|---|---|
| BZタブ「現在の状況」の候補行 | 今のAT間の％を併記（見出しは `候補（％は設定1の場合）：`） |
| BZタブ「過去のAT間」の候補行 | 閉じたAT間の％を併記（カードと同じルール） |
| BZシナリオカードの各AT間の行 | 候補行に％を併記（終わったAT間にも入る） |
| BZシナリオカードの注記 | 3行目に `％は設定1の選択率に基づく参考値。設定1否定が出ると表示しません` |
| ガイド `mhsunbreak-guide.html` | 「シナリオの参考％」の節（§9-101） |

**出さない場所**：なな様テンプレ（通常／収支帳用。v05 は不変）、画像カード、設定推測、
テーブル別の成功／回数、保存データ。

### 4.1 カードの収まり

- 候補行は右寄せ。**見出しと本文を別に置く**ので、入らないときは見出しだけ1段小さくして
  ％の大きさを保てる。それでも1行に入らないときは本文も1段落とす（本文 26→22→19→16px、
  見出しは本文と同じか1段下。％の数字を見出しより小さくはしない）
- 実測（390px の実機幅・右端は送り幅）

  | 候補 | 見出し | 本文 | 候補行の左端 | 右端 |
  |---|---|---|---|---|
  | 3つ（アイキャッチあり） | 26px | 26px | 404 | 1010 |
  | 4つ | 26px | 26px | 292 | 1010 |
  | 9つ | 16px | 16px | 213 | 1010 |
  | ％なし（設定1否定） | 26px | 26px | 576 | 1008 |
  | 該当なし | −（見出しなし） | 22px | 504 | 1009 |

  左端はいずれも「AT間n」の見出し（右端153）・アイキャッチ（同315）より右で、掛からない。
  **候補9つのときだけ 16px まで落ちる**（見出しを1段小さくしただけでは AT間の見出しに掛かるため。
  ％を縮めない指示に対する例外。2行に折り返す案も出せるが、まずは1行で収める形にした）
- 注記が2行→3行になるため、下部ブロックの定位置を **852px → 822px** に上げた
  （テーブル別の成績 866 → 注記 922／952／982 → クレジット 1014／1044）

### 4.2 高さ可変（対応済み。行の省略なし）

**当初は8行以上でカードの下部が溢れていた**（行ブロックが下部ブロックの定位置822pxを越え、
注記がクレジット行と重なり、3行目がキャンバス外に掛かっていた。改修前から同じ）。
2026/10/11 夢爽の差し替え指示で、**キャンバスの高さを可変にして全AT間を描く**ことで直した。
`SC_ROWS`（1枚に載せる上限8件）と「ほか n件（古いAT間）」の行は撤廃した。

- 高さ ＝ 固定部（見出し・テーブル別の成績）＋ AT間の行 × 行数 ＋ 注記3行 ＋ クレジット2行
- 描く前に**行の高さを測る**（`scenarioRowBlock(x,font,row,y,draw)` を `draw=false` で1周。
  折り返しが `measureText` に依るため、座標の進み方は測るときと描くときで同じ流れを通す）
- 注記・クレジットは行ブロックの直下に**相対**で積む（`scenarioBox(rowsEnd,noteLines)`）。
  固定座標（1014／1044）はやめた
- 高さの下限は **1080px**。行が少ないときは `tables` が最短位置 822 に止まり、
  822 → 866 → 注記 922／952／982 → クレジット 1014／1044 → 高さ1080 ＝**従来と同一座標**
- なな様イラストは見出し帯基準のまま（952,106・変更なし）
- `cv.width`／`cv.height` の代入でキャンバスの状態が消えるので、**必ず描く前**に高さを決める
- HTMLの `<canvas width="1080" height="1080">` は初期値として残す（描画時に高さを入れ替える）

実測（AT間ごとの件数 → 高さ。最後の1件だけ開いている形・候補9つの行）

| AT間 | 行ブロック下端 | テーブル | 注記 | クレジット | 高さ | 改修前 |
|---|---|---|---|---|---|---|
| 0件 | 212 | 822 | 922／952／982 | 1014／1044 | **1080** | 1080（同一） |
| 1件 | 284 | 822 | 922／952／982 | 1014／1044 | **1080** | 1080（同一） |
| 7件 | 788 | 834 | 934／964／994 | 1026／1056 | **1092** | 1080 |
| 8件 | 872 | 918 | 1018／1048／1078 | 1110／1140 | **1176** | 1080（注記がクレジットと重なり3行目がキャンバス外） |
| 12件 | 1208 | 1254 | 1354／1384／1414 | 1446／1476 | **1512** | 1080（同じく溢れ） |
| 20件 | 1880 | 1926 | 2026／2056／2086 | 2118／2148 | **2184** | 1080（同じく溢れ） |

0件・1件は改修前と**高さも座標も完全一致**。どの件数でも
