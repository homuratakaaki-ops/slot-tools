ヒント（1文・engine が §9-97 で自動処理するので `<details>` を手で組まない）:

> マイスロの通常ゲーム数を入力します。途中から打ち始めた場合や途中から数え始めた場合は、その時点の数値を開始欄に入れてください。差分があなたのカウント区間になります。実機での確認方法が分かり次第、入力方法を追加します。

### 3-2 分母と 1/x

リコリコと同じく**分母の出典を1つの関数に閉じる**（§9-84）。

```js
function num(v){return Math.max(0,Number(v)||0);}
function rawDenom(S){return num(S.gamesMyslo)-num(S.gamesMysloStart);}
function denom(S){const v=rawDenom(S);return v>0?v:0;}
function denomWarn(S){return num(S.gamesMyslo)>0&&num(S.gamesMyslo)<num(S.gamesMysloStart);}
function syncGames(S){if(S)S.games=denom(S);return S?S.games:0;}
```

- `pages` はリコリコと同じく **描画前に `syncGames(ctx.S)` を呼ぶ**
  （engine がカードのメタ行で `S.games` を直接読むため）
- SC初当りの 1/x・カードの `blocks` / `bottom`・テンプレは**すべて `denom(S)` を通す**
- 現在が開始を下回るときは `.hint.warn` で注意を出し、**分母は0として1/xを出さない**
  （リコリコの `denomWarn` の文言に合わせる）

### 3-3 保存データの引き継ぎ（**消さないこと**）

`storageKey` は `juuou-checker-v1` の**まま**（キー追加のみ）。`normalizeState` で引き継ぐ。

```js
normalizeState(out,src){
  ['gamesMyslo','gamesMysloStart'].forEach(k=>{out[k]=num(out[k]);});
  // 旧版（単欄 id="gIn"）の保存値はマイスロの「現在」欄へ引き継ぐ。
  // 開始欄は0のままなので分母は従来と一致する。新キーが保存データに無いときだけ移す
  // （移行後の再読み込みで二重に移さない）。
  if((src||{}).gamesMyslo===undefined&&!out.gamesMyslo)out.gamesMyslo=num((src||{}).games);
  out.games=denom(out);
  …（counts のクランプは現行のまま）
}
```

engine は `config.normalizeState(out,src)` の形で2引数を渡す。現行の juuou は1引数なので
**第2引数 `src` を受け取る形に直す**こと。
