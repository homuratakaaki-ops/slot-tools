## 4. 入力タブ

上から：当選ごとのG（v0.1 のまま）→ カウント系（v0.1 のまま）→ スイカからのCZ → 規定ゲーム数。

### 4.1 スイカからのCZ（当選／ハズレの2ボタン行×2）

| 行名 | 補足（目安） | 状態 |
|---|---|---|
| 通常時 | 設1:21.9%⇔設6:31.3% | suika.normalD / normalW |
| AT中 | 記録のみ | suika.atD / atW |

説明（1つの「説明を見る」にまとめる。#76 と同じ `hint hint-paras` で段落は改行）：

```
表はスイカ成立時の当選率です。小役変異の緑アイコンからの当選が表に含まれるかは出典に書かれていません。
AT中：設定別の数値は出典で確認できていないため、記録のみです。
```

行のレイアウト（v0.2.1、夢爽 2026-11-01）：目安が数字の途中で折れないよう、補足のある行は paripi の role-row と同じく1行目を「行名＋補足」の全幅（補足は nowrap）にし、2行目に割合と当選／ハズレを置く。360px では nowrap のまま横に並べると収まらない（補足の空き幅が約100pxで、目安は約140px）。

### 4.2 規定ゲーム数（当選／ハズレの2ボタン行×12）

行名は `AT後 100G` … `AT後 850G`、続けて `AT後以外 100G` … `AT後以外 850G`（補足なし）。
説明：「その規定ゲーム数に到達したとき、当選したら当選、しなかったらハズレを押します。設定差は公表されていないため記録のみです。」

### 4.3 当選／ハズレ行の共通仕様（magireco の rateRow と同じ）

- 「当選」＝母数と当選を1ずつ、「ハズレ」＝母数だけ1加算。減算モードでは同じボタンで減らし、ハズレは「母数＝当選」のとき押せない
- 右の表示は `当選/母数 N%`（母数0は `-`）

## 6. テンプレ出力

### 6.1 通常コピー

```
設定判別メモ｜Lパチスロ ゴジラ対エヴァンゲリオン2
累計通常G {合計}G（{件数}件） / AT{回数}回[ 1/x]
_______

{本文}

by slot-tools.jp
ﾃﾝﾌﾟﾚ:鈴白なな様 @nana_szsr
解析出典:ちょんぼりすた様
```

- ヘッダー2行目の AT は原文に行が無いのでヘッダーに出す（モンハンと同じ慣例）。`[ 1/x]` は累計通常G>0 かつ回数>0 のときだけ
- 本文＝原文の正本に、次の変更だけを加えたもの（§9-52/§9-95。書式・表記・順番は一字も変えない）
  1. 規定ゲーム数の行名の置換（上の「テンプレ原文と規定ゲーム数の刻み」）
  2. `■ボーナス当選率` の次の行に `ボーナス▶︎ N回（1/x）` を挿入（**夢爽確認待ちの暫定**）。N＝counts.first（初当り）。`（1/x）` は累計通常G>0 かつ N>0 のときだけ
  3. `0/0` を出現順に `当選/母数` で置換：スイカ 通常 → AT中 → 規定ゲーム数を行ごとに左（AT後）→右（AT後以外）で 100G から 850G まで
  4. 値が空欄の `▶︎`（行末が `▶︎` または `▶︎ `）を出現順に `▶︎ N回` で置換（paripi と同じ書き方。空欄行は「0回」で埋める）：終了画面10行 → エンディング中ボイス5行
- 全項目0のときの本文と原文の差分は、上の 1・2 と「`▶︎ ` → `▶︎ 0回`」（末尾行 `カヲル▶︎` は `カヲル▶︎ 0回`）だけ

### 6.2 収支帳用（プレーン版）

engine の置換に任せる（`▶︎`→`→`、異体字セレクタの除去）。機種側では何もしない。
