## 1. モスラ初期G数の節を挿入

挿入位置：`<h3>ボーナス・AT終了画面</h3>` の表の後、`<h3>終了画面のボイス</h3>` の直前。

現行の文：該当する節なし（終了画面の表から終了画面のボイスへ続く）。

→ 新しい文：

### ゴジエヴァアタック モスラの初期G数

ゴジエヴァアタックでモスラが選ばれたとき、初期G数が44G・55G・66Gなら押します。終了画面のモスラとは別の項目です。

## 2. 終了画面のボイス

挿入位置：`<h3>終了画面のボイス</h3>` 直下の段落。

現行の文：ボーナス・AT終了画面でPUSHを押した際のボイスを記録します。示唆内容・出現率は調査中です。ED中ボイスとは別項目で、テンプレへは出さず詳細カードで確認します。

→ 新しい文：ボーナス・AT終了画面でPUSHを押した際のボイスを記録します。示唆内容は各行に表示しています。天井や次回ボーナスについての示唆で、設定の示唆ではありません。ED中ボイスとは別項目で、テンプレへは出さず詳細カードで確認します。

挿入位置：`<h2>カードとテンプレ</h2>` 内の次の段落。

現行の文：カードにはボーナス初当り・ATの1/xと累計通常Gを表示します。詳細カードにはカウント系、G侵食役、ボーナス当選率、スイカCZ、規定G、終了画面、終了画面のボイス、EDボイスの記録を表示します。終了画面・終了画面のボイス・EDボイスには記録合計に対する割合を併記します。

→ 新しい文：カードにはボーナス初当り・ATの1/xと累計通常Gを表示します。詳細カードにはカウント系、G侵食役、ボーナス当選率、スイカCZ、規定G、終了画面、モスラ初期G数、終了画面のボイス、EDボイスの記録を表示します。終了画面・終了画面のボイス・EDボイスには記録合計に対する割合を併記します。
