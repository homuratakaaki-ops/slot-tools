## 4. 入力タブ

当選ごとのG → カウント系 → G侵食役 → ボーナス当選率 → スイカからのCZ → 規定ゲーム数。

G侵食役は上表順の9行、ctx.crow、hot:false。共通hint：

「G侵食役の成立後、5G以内に小役が成立すると変異が発生します。発生した変異の回数を数えます。設定差は公表されていないため記録のみです。」

ボーナス当選率は1セクション。絵文字付き小見出しは正本通り、その下に通常／高確／超高の3行。
cbは全状態、blue/redは通常・高確が既存rateRowの当選／ハズレ。分母はそのグループの役がその状態で成立した機会数D、分子はそのうちのボーナス当選数W。表示はratio()に集約し `W/D xx%`、D=0では%なし。
残り5行は成立＝当選回数のctx.crowで、補足は「当選確定（回数のみ）」。

共通hint（指定文そのまま）：

「グループの役が成立したとき、ボーナスに当選したら当選、しなかったらハズレを押します。当選率が100%の欄は、回数だけを数えます。設定差は公表されていないため記録のみです。」

加算モードは当選でD/Wを各+1、ハズレでDだけ+1。減算モードは各-1、D=W時のハズレは無効。回数は±1、下限0。保存・取消は既存エンジンを使う。

## 本番ガイドの反映案

以下は `godzieva2-guide.html` に追加する文案。ガイド本体は今回変更しない。

### G侵食役を記録する

入力タブの「G侵食役」で、発生した変異の回数を数えます。小役変異・増殖変異・画面分裂・ブースト・活性化・月蝕変異・Ｇ連鎖・勝利変異・確定変異の9項目です。設定差は公表されていないため記録のみです。「確定変異」という名称を設定確定の意味として扱うものではありません。

### 小役によるボーナス当選を記録する

「ボーナス当選率」で成立役のグループと、そのときの状態（通常・高確・超高）を選びます。当選したら「当選」、しなければ「ハズレ」を押します。表示の分母はその条件で役が成立した回数、分子はボーナスに当選した回数です。当選率が100%の欄は、回数だけを数えます。設定差は公表されていないため記録のみです。

### コピーと詳細カード

コピー本文は鈴白なな様のv02テンプレに対応します。ボーナス初当りとATの回数・1/xはヘッダーに表示します。規定G先頭100g、弱ﾁｪ/ﾍﾞﾙ3連の超高の分数、虹グループの通常・高確の回数表記は夢爽判断による変更で、なな様へ確認中です。詳細カードにも新項目を表示し、多い場合は末尾を「ほか N項目」で省略します。
