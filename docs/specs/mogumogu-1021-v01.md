■ 2. checker-data/mogumogu.js
 (a) 示唆タブ：くまトロフィーのセクションの直後に「エンディング中の巻物」セクション。
     const SCROLL=[
       ['blue','青巻物','デフォルト',0,'青'],
       ['yellow','黄巻物','高設定期待度UP(弱)',0,'黄'],
       ['green','緑巻物','高設定期待度UP(強)',0,'緑'],
       ['red','赤巻物','設定2以上濃厚',2,'赤'],
       ['rainbow','虹巻物','設定6濃厚',6,'虹']
     ];
     表示名・示唆文は出典の表記どおり（上の転記と同じ文字）。
     状態キー S.scroll（DEF に 0 埋め）。出現有無型なので割合は出さない（トロフィーと同じ crow 呼び出し、pct を渡さない）。
     見出しのサブは「計n回」（トロフィーと同じ）。
     確定演出：allCert に SCROLL の rank>0（赤・虹）を含める。order の基準は 15（トロフィー10 と終了画面20 の間。
     同じ rank ならトロフィー → 巻物 → 終了画面の順）。certCount・bestCert・カードの「確定演出 計n回」に自動で乗る。
     tierText は既存のまま使う（「設定2以上濃厚」→「2以上」、「設定6濃厚」→「6濃厚」）。
     hint：「エンディング中にレア役が成立すると出る巻物の色を記録します。出典の一覧は青・黄・緑・赤・虹の5色で、赤（設定2以上濃厚）と虹（設定6濃厚）は確定演出として数えます。出るたびに必ずどれかが選ばれる振り分けではないため、割合は表示しません。」
     「解析待ちの示唆」セクションの hint から「エンディング中の1枚絵、」を削除する（今回入るため）。他の文言は変えない。
 (b) 入力タブ：初当りセクションの cgrid で、CZ当選の直後（AT初当りの前）に内訳2行。
     ${ctx.crow('czType.taisen','モグモグ大戦','設1:1/354⇔設6:1/324',0)}
     ${ctx.crow('czType.mogura','モグラ叩き','設1:1/3778⇔設6:1/2507',0)}
     行名は素の名前（既存機種に内訳行の記号の慣例が無いため）。
     状態キー S.czType={taisen:0,mogura:0}。合算 counts.cz は従来どおり（内訳を押しても合算は増えない）。
     1/x・割合は出さない（回数のみ）。推定・確定演出には使わない。
     hint（初当りセクションの既存 hint の前に追加）：「CZの種別が分かったときだけ内訳を押します。合算のCZ当選は従来どおり押してください。モグラ叩きは設定5・6で約1/2510、設定1〜4は1/3101〜1/3778です。」
 (c) normalizeState の対象と mergeKeys に 'scroll','czType' を追加。旧データ（キー無し・null）は 0 補完、未知キーは残す、負数・不正値は 0、文字列数字は数値化（既存の counts と同じ扱い）。
 (d) tplText：
     - 「■初当り」節の CZ当選の直後に「CZ内訳 モグモグ大戦▶n回」「CZ内訳 モグラ叩き▶n回」。内訳が両方0なら2行とも出さない。
     - 「■くまトロフィー」節の直後に「■エンディング中の巻物」節（tplSection(… ,SCROLL,S.scroll,0)：割合なし、確定は段位付き）。
 (e) detail：初当りの items に「モグモグ大戦」「モグラ叩き」を CZ当選の直後に追加。くまトロフィーの直後に {title:'エンディング中の巻物',items:detailItems(SCROLL,S.scroll)}。
 (f) カード下段（bottom）：右列（x:560、現在4行）に2行追加。
     row(shown('巻物',codes(SCROLL,S.scroll)),total(SCROLL,S.scroll))
     row(`CZ内訳 大戦${taisen}回・叩き${mogura}回`,taisen+mogura)
     カードPNGで行が下端・フッターに重ならないことを確認する。収まらない場合は追加せずに報告する（行間・フォントを勝手に変えない）。
     blocks・chart は変更しない（確定演出の数には巻物が自動で入る）。
