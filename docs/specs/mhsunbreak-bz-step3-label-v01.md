# モンハンSB BZ入口 手順3の行にテーブルと結果アイコンを併記（画面のみ）

夢爽の指示：2026-10-13。ブランチ `feat/mhsunbreak-bz-step3-label`（PR #47 マージ後の main から）。テスト版先行（§9-108）。

## 変更内容

対象は `checker-data/mhsunbreak.js` の `inputSection()` にある「3. 成功／失敗」の行（`.crow.pick-row` の `.lbl .nm`）だけ。

- 現在：テーブル選択後は `TABLE_NAMES[picked]`（例「③ ライゼクス」）だけを出している。
- 変更後：手順2で結果アイコンの位置を選んでいる（`pickPos!==null`）ときは
  `③ ライゼクス ・ 結果 3個目 セル` の形にする。
  - 「結果 N個目 X」の X は `ICON_SHORT[TABLE_ICONS[picked][pickPos-1]]`（既存の短い名前）。
  - 結果部分（「結果 N個目 X」）の文字色は既存の `iconColor(アイコン名)` を使う。新しい色表は作らない。
  - 「③ ライゼクス」部分は従来どおり（色も変えない）。
- 位置が未選択（`pickPos===null`、テーブル⑦の自動記録を含む）のときは従来どおりテーブル名だけ。
- テーブル未選択時の「テーブルを選んでください」も従来どおり。

## 折り返し

- 390px で1行に収まらないときは、結果部分（「・ 結果 N個目 X」）をまとめて2行目に送る。
  テーブル名の途中・結果部分の途中では折り返さない（それぞれを nowrap の塊にし、塊と塊のあいだでだけ折れる）。
- 横はみ出し 0（`.lbl` の scrollWidth ≤ clientWidth、行全体もはみ出さない）。右の［成功］［失敗］ボタンの大きさ・位置は変えない。
- 最長ケース（例：⑤ オロミドロ亜種・10個目 ＋G、⑥ テオ・テスカトル・2個目 テオ）を 360 / 390 / 412px で実測する。
