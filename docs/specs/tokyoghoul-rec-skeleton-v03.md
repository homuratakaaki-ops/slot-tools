## 1. 目的と対象（Step 0）

### 目的
- 東京喰種の実戦を、状況別CZ・AT分析（台帳11/20）に必要な単位で、**打ちながら構造化して残す**

- CZ・ATの前後のクレジットを残し、区間ごとの差枚を出す

### 二層構造での置き場所
| 層 | 置くもの |
|---|---|
| 記録（実戦中） | tools/rec（本線）の機種定義 `tokyoghoul`。店舗連動・投資回収・再プレイ・ノート・JSON出力は既存を共用 |

- 設定判別チェッカー（tokyo_ghoul.js）は**変更しない・自動連携しない**

## 3. 流れ（時系列の一文リスト）

【入力】＝プレイヤーが入れる／【自動】＝ツールが進める

1. 着席：機種「東京喰種」、店・台番号・開始G（実G/液晶G）・開始持ちメダル・CZスルー数・着席時の状況・前回の当選・着席メモ【入力】
2. 通常時に示唆が出たら「示唆」→〔アイキャッチ／招待状（規定G数示唆）／招待状（設定示唆）／ゲーム数前兆〕→内容・メモ【入力】
3. CZ当選：種別（レミニセンス／大喰いの利世）・契機・突入時のクレジット（任意）・メモ【入力】
4. CZ成功：成功時のクレジット（任意）・メモ【入力】→ AT開始【自動】
5. CZ失敗：1枚絵（任意）・今のG数（初期値 実6／液晶0）・クレジット（任意）・メモ【入力】→ スルー＋1【自動】→ 通常時
6. CZを経由しないAT：種別「AT直撃」・契機（直撃／引き戻し／天井／その他）・クレジット（任意）・メモ【入力】
7. エピソードボーナス：当選時クレジット（任意）【入力】→ 終了時クレジット（任意）【入力】→ AT開始【自動】
8. AT中：喰種対決ごとに相手・勝敗・BITES獲得枚数（勝利時・任意）・メモ【入力】。有馬に勝ったら「有馬権利」【自動】
9. エンディング：「エンディング」→ EDカード専用画面で14分類を＋／−【入力】
10. AT終了：画面の獲得枚数（任意）→AT終了画面（任意）→ナミちゃんトロフィー（任意）→クレジット（任意）→総回転数（任意）→今のG数→メモ【入力】
    - 有馬権利あり、またはED到達 → 有馬ジャッジメントへ【行き先ボタン】
    - それ以外 → 通常時。スルー0【自動】
11. ジャッジメント成功：クレジット（任意）・メモ【入力】→ CCGの死神【自動】→ 終了 → AT再突入（初当たりに数えない）【自動】→ 8へ
12. ジャッジメント失敗：今のG数（初期値 実6／液晶0）・クレジット（任意）・メモ【入力】→ 通常時（スルーは増えない）。次のCZに「有馬失敗後」の印【自動】
13. 引き戻し → 6として記録
14. ヤメ：終了時の持ちメダル・台の総回転数・終わりのメモ（既存）

## 5. 引き継ぎ・リセット規則

| 値 | 規則 |
|---|---|
| CZスルー数 | 着席時に入力。CZ（レミ・利世）失敗で＋1。AT終了で0。**ジャッジメント失敗は数えない**。手動±で訂正可 |
| 実G・液晶G | CZ失敗・ジャッジメント失敗の終了シートは**初期値 実6／液晶0**（違えば直す）。AT終了など、そのほかの終了シートは既存どおり「今のG数」を入れる |
| 有馬権利 | AT中に有馬へ勝利で付く。AT終了でジャッジメントに使って消える。新しい初当たりATで0 |
| 有馬失敗後の印 | ジャッジメント失敗で付き、次のCZ当選に記録して消える |
| EDカード | EDごとに別の記録（0から開始）。累計は保存せず合算で出す |
| クレジット | 入れた場面の値だけを残す。入れなければ「未入力」。推計で埋めない。持ちメダル・収支とは連動しない |
| 店舗・レート・貯メダル口座 | 既存の店舗連動どおり |
| セッションまたぎ | スルー・権利は引き継がない（台移動は別セッション）。ED累計だけは同じ日・同じ台の記録を合算して表示する |

## 6. 保存する値／しない値

### 方針
- 一次データ（入力そのもの）だけ保存。導出値は保存しない
- 既存の保存項目の意味は変えない。東京喰種の記録にだけ項目を足す
- 未入力は `null`、0は0
- 選択肢は**内部キー＋表示名**で持つ（§9-64）。既存チェッカーにあるものはそのキー（`edWhiteW`、`bronze`、`kanekiKirishima`、`evenDinner` など）を使う

### 台（セッション）に足すもの
| 項目 | 内容 |
|---|---|
| machineId／machine | `tokyoghoul`／「東京喰種」（これまでの汎用記録と同じ名前） |
| setup.c3 | 着席時のCZスルー数（既存の項目） |
| setup.seatState | 着席時の状況：`resetConfirmed` リセット確認／`resetGuess` リセット推定／`keepConfirmed` 据え置き確認／`unknown` 不明 |
| setup.lastHit | 前回の当選：`czFail` CZ失敗／`atEnd` AT終了／`judgeFail` 有馬失敗／`unknown` 不明 |
| edRuns[] | EDごとの記録：`{id, startedAt, counts:{14分類キー:数}, note, fixes[]}` |

### 記録行（events）に足すもの
| 記録 | 足す項目 |
|---|---|
| すべての記録行 | `note`（任意メモ。空なら持たない） |
| クレジットを聞く記録（CZ当選・CZ成功・CZ失敗・AT当選・EP当選・EP終了・AT終了・ジャッジメント成否） | `cr`（クレジット、任意） |
| 示唆 | `sel:{kind, key, label}`。kind＝`eyecatch`／`inviteG`（規定G数示唆）／`inviteSet`（設定示唆）／`zenchouG`（ゲーム数前兆） |
| CZ失敗 | `sel.czCard`（任意、1枚絵） |
| 喰種対決 | `sel:{opp, result}`（result＝`win`／`lose`）、`bites`（数値・任意、勝利時のみ） |
| AT終了 | `shownGain`（画面の獲得枚数・任意）、`sel:{screen, trophy}`、`totalG`（任意） |
| ジャッジメント開始 | `via`：`ticket`（有馬勝利）／`ending`（ED後） |
| 次のCZ当選 | `afterJudgeFail:true` |
| EDカード確定・訂正 | `edId`、確定時の内訳（文字ログ用） |

**クレジットは既存の持ちメダル（money.credit）には入れない**。持ちメダル・差枚・収支は従来どおり、開始時・途中の残数調整・ヤメ時の値で計算する。CZ失敗とAT終了のシートにある既存の「今の持ちメダル」欄は、東京喰種ではクレジット欄に置き換える（同じ画面に似た数字を2つ並べないため）。

| CZ回数・成否 | CZ当選行・成功行・失敗行の数（ジャッジメントを含めない） | 当選・成否 |
| AT初当たり回数 | AT開始行のうち、契機が「死神後」でないもの | 当選 |
| 有馬ジャッジメント | 成功数／（成功＋失敗） | 成否 |
| 喰種対決 | 相手ごとの勝ち／負け | 喰種対決 |
| EDカード 今回 | そのEDの counts | ED画面 |

| **AT獲得枚数（1回ごと）** | そのATの終了時クレジット − そのATの開始点のクレジット | 下表 |
| 画面の獲得枚数 | 入力値そのまま（クレジット差とは別に表示。計算に混ぜない） | AT終了 |
| CZの差枚 | CZ終了時（成功・失敗）のクレジット − CZ突入時のクレジット | CZ当選・終了 |
| 差枚・収支（台全体） | 既存 profit()（変更なし。クレジットは使わない） | 既存 |

AT1回ごとの開始点：

| ATの入り方 | 開始点のクレジット |
|---|---|
| CZ成功 | CZ成功時 |
| エピソードボーナス | EP終了時 |
| 直撃・引き戻し・天井 | AT当選時 |
| 死神後の再AT | ジャッジメント成功時（死神の上乗せは再ATの終了画面に含まれるため） |

## 9. 取り消し処理

既存の「1操作＝1まとまり」で戻す方式に乗せる。§9-68に従い、状態と判定に使う値を一緒に戻す。

| 操作 | 1操作に含むもの | 取り消したとき |
|---|---|---|
| 示唆 | 示唆行 | 行が消える |
| CZ当選 | 当選行 | 通常時に戻る |
| CZ成功 | 成功行＋AT開始行 | **CZ中に戻る**（既存機種は成功とAT開始が別操作。東京喰種だけ1操作に） |
| CZ失敗 | 失敗行 | CZ中に戻る。スルー−1、G数も戻る |
| EP終了 | 終了行＋AT開始行 | EP中に戻る |
| 喰種対決 | 対決行 | 行が消える。有馬勝利で付いた権利も消える |
| エンディング | ED開始行＋EDの記録枠 | AT中に戻る。EDカードが入っていれば「N枚も消えます」と確認してから消す |
| EDカードの＋／− | 取り消しの対象にしない（−で直す） | — |
| 前回EDの訂正 | 訂正行（前後の数を保持） | 訂正前の数に戻る |
| AT終了 | 終了行（＋ジャッジメント開始行） | AT中（ED中ならED中）に戻る。スルー・権利も戻る |
| ジャッジメント成否 | 成否行（＋死神開始行） | ジャッジメント中に戻る。「有馬失敗後」の印も戻る |
| 死神終了 | 終了行＋AT開始行 | 死神中に戻る |

- クレジットは各記録行の中に持つので、行が消えれば一緒に消える（持ちメダルのような巻き戻し処理は要らない）
- EDカードの数は巻き戻し用スナップショットに**入れない**（ED後の操作を取り消したとき、その後に直したカード数まで巻き戻るのを防ぐ）
- 終了した台は既存どおり記録の修正画面で直す

## 10. 既存機種・共通部分への影響

### 共通部分に足す機能（東京喰種の定義で指定したときだけ動く）
| 足す機能 | 既存機種への影響 |
|---|---|
| 当選・CZ／EP／AT／ジャッジメント終了シートのクレジット欄 | なし（指定時のみ。既存の持ちメダル欄は既存機種ではそのまま） |
| CZ成功時のシート（今は押すと即確定） | なし（既存は即確定のまま） |
| CZ成功→AT開始を1操作にする | なし |
| 「示唆」1ボタンから種類を選ぶメニュー | なし（新しい部品） |
| シート内の数値欄（BITES・画面の獲得枚数・総回転数） | なし（新しい部品） |
| 権利の自動付与に「相手＝有馬」の条件 | からくりの「激情ジャッジ3回」は今の判定のまま |
| 失敗時のG数初期値（実6／液晶0） | なし（既存の「G数が決まっている当選」の仕組みを使う。表示文言だけ東京喰種用に） |
| EDカード専用画面・edRuns | なし |
| 各記録の任意メモ（note項目） | 既存機種は今の方式（本文に連結）のまま |

### 変えないもの
- 店舗連動・貯メダル口座・再プレイ上限（11/24 本番反映分）
- 差枚・収支の計算（profit）、ノートの集計、JSONの取り込み・書き出し形式（追加項目を通すだけ）
- 設定判別チェッカー（tokyo_ghoul.js）と、からくり専用のチェッカー送信。東京喰種の定義には送信設定を付けない
- kado-note
- これまでの108件：自動変換しない。機種名が同じなのでノートの機種別集計ではまとまる

### 確認方法（仕様書で定める）
- からくりサーカス2・ハイビリターン30・汎用の通し操作を、改修前後で同じ結果になるか確認
- テスト版（acct-test.html）で夢爽の実機確認 → 本番は夜に反映（保存データに触るため）

## 12. 仕様上の問題・注意点

1. **アイキャッチと§9-61**：ちょんぼりすたによるとアイキャッチはステージチェンジで出る。招待状・ゲーム数前兆と同じく通常時そのものが発生場面なので、通常時の「示唆」ボタンで§9-61に沿う（解消）
2. **共通部分への改修量**：機種定義だけでは足りず、§10の9機能を共通部分に足す。指定時だけ動く作りにし、既存3機種の通し操作で回帰確認する
3. **クレジットの差枚は目安**：途中の投資・再プレイ・計数があれば実際の獲得とずれる。補正はせず「※途中で投資あり」と添えるだけにする
4. **「実6／液晶0」は初期値**：実機と違えば手で直す（夢爽の回答どおり）。違うことが多ければ、仕様書段階で初期値を直す
5. **画面の獲得枚数とクレジット差は別の数字**：両方並べて出すが、どちらかで他方を上書きしない
6. **メモの持ち方が機種で2通りになる**：既存機種はメモを本文に連結、東京喰種は note に分離。既存機種をそろえるのは別件
