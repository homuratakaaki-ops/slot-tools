# 示唆表記を「濃厚」にそろえる 実装指示書 v01

発行: ツムギ（2026-10-04）／実装: ミコト／裁可: 夢爽
ブランチ: `chore/wording-noukou`（main の `3c3f807` から分岐）

## 0. 方針（夢爽決定）

- **個別の示唆表記は「濃厚」**。「設定2以上濃厚」「設定6濃厚」「設定2・4・6濃厚」「偶数設定濃厚」。
  解析訂正時の逃げ道として断定しないため
- **分類名は「確定演出」のまま**。セクション見出し、カードの欄名、「確定演出 計n回」「確定演出 なし」、
  サマリーの「終了画面確定」などは**触らない**
- 「濃厚示唆」「最強」は使わない（実機の固有名詞は除く）
- 2026-10-04 の洗い出しで出た「濃厚→確定演出」の置き換え案は**中止**。逆方向に揃える

### 守ってほしい歯止め

- **UI の変更を自分の判断で足さない。見た目を直したくなったら実装せずに報告すること。**
  本書に書いていない項目追加・レイアウト変更もしない（動作の修正・検証の追加は自由）
- 共通ファイル（`checker-engine.js` / `checker-bayes.js`）は**変更しない**
- `checkers.html` / `sitemap.xml` / `index.html` / `ARCHITECTURE.md` には触らない
- 状態キー・保存データは**一切変えない**（移行を発生させない）

## 1. 置き換えの規則

次の4パターンだけを置き換える。**他の「確定演出」は残す。**

| 変更前 | 変更後 |
|---|---|
| `設定2以上確定演出` / `設定3以上確定演出` / `設定4以上確定演出` / `設定5以上確定演出` | `設定2以上濃厚` …（同形） |
| `設定6確定演出` | `設定6濃厚` |
| `設定2・4・6確定演出` | `設定2・4・6濃厚` |
| `設定1否定＝設定2以上確定演出` | `設定1否定＝設定2以上濃厚` |

正規表現で言えば `設定([0-9０-９・]*(?:以上)?)確定演出` → `設定$1濃厚`。

**残すもの（置き換えてはいけない）**

- 単独の「確定演出」（セクション見出し・カードの欄名・ヒント文中の分類名）
- `'確定演出 計'+n+'回'` / `'確定演出 なし'` / `確定 ${label}(${tier}) ×n` の「確定」
- `shown('終了画面確定',…)` 等のサマリーの見出し語
- `'設定2以上が確定'` のようなサブラベル（「確定演出」ではないので対象外）

## 3【必須】文字列を読む処理を「濃厚」で読めるようにする

3箇所だけ。**強さの判定は従来どおり数値 rank のみ（§9-62）**で、ここは段位の表示文字を作るだけ。

```js
// checker-data/kanokari.js:130 と checker-data/mhsunbreak.js:142
- const m=String(sub||'').match(/設定([0-9・]+(?:以上)?)確定演出/);
+ const m=String(sub||'').match(/設定([0-9・]+(?:以上)?)濃厚/);

// checker-data/mogumogu.js:71
- const m=String(c[2]||'').match(/設定([0-9]+(?:・[0-9]+)*)(以上)?確定演出/);
+ const m=String(c[2]||'').match(/設定([0-9]+(?:・[0-9]+)*)(以上)?濃厚/);
```

mogumogu のテンプレの `(4以上)` が修正前と一字も変わらないこと。

ツムギ側で置換をシミュレートし、**11機種すべてで段位表記が同一**になることを確認済み。

## 4【必須】magireco の項目名を分ける

`checker-data/magireco.js:117`

```js

+ ['descAll','全て降順','設定5以上濃厚（5→4→3→2→1）',5]
```

「全て降順（設定5以上濃厚）」→「全て降順」に短くなる**。カード1行目の段位表記 `(5以上)` は不変。

## 5【必須】tonski は語句だけ置き換える

`checker-data/tonski.js` の `BONUS_END` 6〜8行目は、項目名そのものが示唆文になっている。
**配列全体が示唆の分類単位で記録する設計（§9-63）**で、実機の個別画面名が解析に無いため、
magireco のような項目名の分離は**行わない**（夢爽裁定）。語句だけ置き換える。

```js
- ['set2','設定2以上確定演出','設定2以上が確定',2,'2+'],
+ ['set2','設定2以上濃厚','設定2以上が確定',2,'2+'],
```

1〜5行目の「奇数設定示唆」「高設定示唆・強」と同じ作りにそろう。
カード1行目が「確定 設定6濃厚(6確定) ×1」と重なって見えるのは分類単位記録に付随するもので、
今回の変更で生じるものではない。
