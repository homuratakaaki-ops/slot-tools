## 0. 絶対ルール

1. **`js/play-stats.js` は1バイトも変えない**（集計・計算式は変えない。md5 で確かめる）

4. 「東京喰種の集計」節**以外**（分析の既存部分・台の詳細・ほかの画面）の HTML を変えない
5. 今の節に出ている**数字・件数・注記を1つも消さない**。どれかのタブに必ず出す（§3 の対応表）
6. 数字の書き方（「1/158.5G」「2/4（50.0%）」「-575枚」など）は今の関数（`statsNumber`・`statsRate` など）をそのまま使う
7. 画面の文言に内部・統計用語を使わない（§9-94）。ツール内部の扱いを書いた文も使わない

## 1. 節の構成

```
東京喰種の集計
┌ 対象と条件の帯（いつも見える）────────────┐
│ 対象：自動 4台／確定値 0台／対象外 30件      │
│ 条件：前回の当選＝CZ失敗 ×  規定G数 200〜 ×  │
│ ［絞り込み ▼］               ［すべて解除］ │
└────────────────────────────┘
（絞り込みを開いたときだけ：条件の入力欄）
［概要］［詳細］［履歴］   ← タブ（初期は概要）
（タブの中身）
打った台の記録から数えた値です。機種そのものの確率ではありません。
```

- 帯の「条件」は、何も絞っていなければ「条件：なし」
- タブを切り替えても、絞り込みの条件はそのまま。タブと条件は `page`（今の `page.statsFilters` と同じ扱い）に持ち、保存はしない
- 機種を「L東京喰種」から外したら節ごと消える（今と同じ）

## 2. 絞り込み

- 初期はたたむ（`<details>` など。開閉の状態は `page` に持つ）
- 項目と出し方

| 項目 | 出す条件 | 入力 |
|---|---|---|
| 着席時の状況 | いつも | 選択 |
| 開始時CZスルー | いつも | 選択（データにある値だけ。今と同じ） |
| 前回の当選 | いつも | 選択 |
| 前回CZの当選契機 | 前回の当選＝CZ失敗 | 選択 |
| 前回CZの規定G数 | 前回CZの当選契機＝規定G数 | 下限〜上限を**横並び**（「◯以上」「◯未満」） |
| 前回CZ当選時の液晶G | 前回の当選＝CZ失敗 | 下限〜上限を横並び |
| 前回ATの結果 | 前回の当選＝AT終了 | 選択 |

- 隠れた項目の条件は**消す**（見えない条件で絞られたままにしない）
- 数字の空欄は「条件なし」
- 解除：帯の条件の各「×」でその条件を外す。「すべて解除」で全部外す。下限・上限の行にも「×」（その行を空にする）。今の「条件を外す」ボタンはこれに置き換える
- 数字はテンキー（今と同じ `prepareNumbers`）

## 3. タブの中身と、今の表との対応

### 概要（初期表示）
2列のカード。大きな数字＋小さな補足。

| カード | 大きな数字 | 小さな補足 |
|---|---|---|
| メダル収支 | 実差枚 合計 | 確定 ◯台／未確定 ◯台 |
| 1台平均 | 実差枚 平均 | — |
| 勝率 | 勝率（%） | ◯/◯台 |
| AT初当たり | 確率 | ◯回 |
| CZ当選 | CZ合算確率 | ◯回 |
| CZ成功率 | CZ合算成功率（%） | 成功◯・失敗◯・不明◯ |
| 通常G | 通常G | — |

- カードの下に小さく：印（推定あり◯件／補正あり◯件／G数の不整合◯件）
- 差枚のプラスは既存の `positive`、マイナスは `negative` の色

### 詳細
- **CZ種類別**：通常CZ（レミニセンス）・上位CZ（大喰いの利世）を1つずつのまとまりで、回数・確率・成功率・成功/失敗/不明
- **CZの契機別**（今の「CZごとの表」）：種別×契機×規定G数ごとに、当選・成功・失敗・不明
- **ATの経路別**：レミ経由・利世経由・EP経由・直撃（規定G数）・直撃（レア役）・天井・引き戻し・不明、EP 回数
- **有馬ジャッジメント**：回数・成功率・成功/失敗/不明、有馬失敗後のCZ
- 0回の項目は各まとまりの下で「0回の項目（◯件）」としてたたむ（開ける）

### 履歴
縦のカード（横長の表にしない）。

- **CZ当選の履歴**（今の「CZ当選の一覧」）：1件1カード。1行目＝日付・種別、2行目＝契機・規定G数・液晶G、右上に成否。成功・失敗・不明は**色と文字の両方**で分ける
- **CZ失敗の次**（今の「失敗の次」）：1件1カード。「着席前／台の中」、失敗したCZ（契機・規定G数・液晶G）→ 次の当選（種別・契機・規定G数・液晶G）またはヤメ（通常◯G）
- 値が「—」の項目は、カードの中では出さない（例：「規定G数：—」を省く）。値が全部無い前回CZは「前回CZ（詳細なし）」
- 並びは今と同じ順

### 今の行 → 新しい場所（全部どこかに出す）

| 今の行 | 新しい場所 |
|---|---|
| 自動◯台／確定値◯台／対象外◯件 | 帯 |
| 通常G | 概要 |
| CZ合算 回数・確率・成功率 | 概要 |
| 通常CZ・上位CZ 回数・確率・成功率 | 詳細 CZ種類別 |
| AT初当たり 回数・確率 | 概要 |
| AT 各経路 | 詳細 ATの経路別 |
| EP | 詳細 ATの経路別 |
| 有馬ジャッジメント・有馬成功率・有馬失敗後のCZ | 詳細 有馬 |
| 実差枚 合計・平均・勝率・確定/未確定 | 概要 |
| 印 | 概要の下 |
| CZごとの表 | 詳細 CZの契機別 |
| CZ当選の一覧 | 履歴 |
| 失敗の次 | 履歴 |
| 注記（打った台の記録から…） | 節の一番下（どのタブでも） |

## 4. 他機種に流用できる形

- 描画の関数は、`PlayStats.aggregate`・`czRows` の結果と、**表示の設定**（機種ごと）だけを受け取る形にする
- 表示の設定（カードの並び、CZ種類の表示名、ATの経路の表示名、有馬のまとまりの有無など）は日誌の中に `def.id` ごとの1つのオブジェクトで置く。描画の関数の中に「レミニセンス」などの東京喰種の言葉を直書きしない
- 今回、表示の設定を持つのは東京喰種だけ

---

## 5. 見た目

- 既存の日誌の色・部品（`panel`・`muted`・`positive`・`negative`・ボタン）を使う。新しい色は成否の3つまで（既存の変数で足りればそれを使う）
- 大きな数字と補足で文字の大きさに差をつける
- 360px・390px で横にはみ出さない。タップできる所は高さ44px以上
- 装飾（影・グラデーション・アイコン）は足さない
