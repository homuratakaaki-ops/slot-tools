## 1. 判断

1. 黒トロフィー（夢爽判断）：出典の文言は「次回銅以上のトロフィー出現濃厚」。銅＝設定2以上のため2以上として扱う。補足は出典の文言に「（設定2以上濃厚として数える）」を添え、rankを2とする（ツムギ 11/2、指示書の補足どおり）。
2. 条件付き示唆（夢爽判断）：友・義・乱、魔導紀元史・金城グループマーク・プラント・尊士の剣・禁断のオブジェは条件成立を確認してから記録。注意文をF見出し直前に1回だけ、既存変数var(--gold)の専用class condition-noticeで常時表示。共通エンジンの折りたたみ対象は .hint のため .hint は使わない。
3. switch on!!・牙狼斬馬剣・トントンは出典文言どおり条件なし（出現時点で濃厚）として扱う（シオン 11/2、出典文言に合わせて修正）。UI補足の「出現時点で」は指示書指定。出典表の文言とは表で分離する。

注意文：友・義・乱、魔導紀元史・金城グループマーク・プラント・尊士の剣・禁断のオブジェは、条件を満たしたと確認できたときだけ押してください。出ただけでは押しません。

## 4. 示唆・カード・コピー

各行は ctx.crow。rank>0・偶数設定濃厚・否定はhot。A〜G順、見出し右は計n回、各群の説明はhint1つ。
ランプ群内はダイヤ／GAROロゴ小見出しで分ける。分母はgroupTotalに集約。
CERTはrank>0とexclude=[1,3,5]のみ。偶数設定濃厚の比較rankは2、表示は2・4・6。
rank=0かつexclude=[N]の否定はCERTに含めず、サマリー「否定 設2・設3・設4」（未記録は「否定 −」）にまとめる。
blocksはトータルCZ／BONUS初当り／確定演出 計n回／通常G。
bottom左は確定演出・否定・既存2カウント、右は既存累計通常G。
detailはカウント系の後にBONUS終了／RUSH終了／トロフィー／枚数表示／3000枚ランプ／ステップアップ／アイテム。0回行を除き、A・Bだけpercent:trueとグループ合計のdenominatorを渡す。他群に分母を渡すとエンジンが％を描くため渡さない。40行超は既定の「ほか N項目」。
ランプ短縮名：ダイヤ白、ダイヤ水色、ダイヤ緑、ダイヤ黄、ダイヤオレンジ、ロゴ全オレンジ、ロゴARO橙、ロゴRO橙、ロゴO橙、ロゴ全虹、G青ARO黄、A青GRO黄、R青GAO黄
コピーは「累計通常G ${logText(S)} / 確定演出${strongCount(S)}回」、カウント系の後に回数>0の行のみを群別「行名▶n回」。A・Bだけ「 (xx%)」。
