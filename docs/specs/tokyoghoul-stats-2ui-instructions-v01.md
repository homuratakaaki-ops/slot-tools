## 2. 作業内容

仕様書 §1〜§5 のとおり。要点：

1. 「東京喰種の集計」節を、帯（対象と条件）＋たたんだ絞り込み＋3タブ（概要・詳細・履歴）＋注記の形に作り直す
2. 絞り込み：前回状況に合わせて項目を出し分け、隠れた項目の条件は消す。下限〜上限は横並び。帯の「×」・行の「×」・「すべて解除」
3. 概要は2列のカード、詳細は0回の項目をたたむ、履歴は縦カード（成否は色と文字）
4. 描画の関数は集計結果と機種ごとの「表示の設定」だけを受け取る形。表示の設定は日誌の中に `def.id` ごとに置き、今回は東京喰種だけ
5. 今の「条件を外す」ボタンは、行の「×」に置き換える
