# サンブレイク：潜水艇の規定リプレイ周期メモ

依頼者：夢爽／2026-10-21。ネネ実装・自己テスト、シオン独立検収。合格前に本番反映しない。開発の土台はPR #57 head `7aefae422910dacd2c2d87f7558f1f039d8524fb`、追加差分は別Draft PRに分ける。ARCHITECTURE §5の既存待ち行列にはない本人の追加依頼として扱う。

## 入力と表示

- 設定判別カウンターと新BZ予測の「オトモ潜水艇」で、ガルク同乗あり／なしを選ぶと、規定リプレイの1・2・3・4・5周期目／不明を必須選択する。
- BZ回数とは別の手動メモ。周期の自動カウント、当選率・狙い目・設定やシナリオ推測への利用は追加しない。
- 選択途中でも潜水艇の記録を保存し、ページを閉じて再読込したら周期選択を復元する。Escapeで省略せず、不明を選んで進める。取り消しボタンはその潜水艇1件だけを取り消す。
- 履歴に同乗区分と「規定リプレイ 3周期目」などを併記。カウンターはその履歴の詳細から、新BZ予測は「周期を訂正」から同じ6択で訂正する。
- 過去の記録に周期を推測で追加しない。以前の記録は「周期未記録」と表示し、本人が訂正したときだけ項目を追加する。未記録と明示選択の不明を区別する。
- 新しい周期選択画面は両ツールとも2列3行。48px以上の選択領域、320/360/390/412px・高さ530px、フォーカス制御を確認する。

## 保存と引き継ぎ

- 既存キーとschemaは維持。潜水艇イベントに `replayCycle: 1..5 | 'unknown'` を追加するだけで、旧記録や未知項目を書き換えない。
- 選択途中は同じイベントに `pendingReplayCycle:true` を持たせる。最初の記録と周期選択は別のUndo操作として復元可能。周期訂正で同乗区分・他のメモ・集計を変更しない。
- 途中の「不明」は保存保護の仮値で、選択途中を示すフラグと区別して扱う。自動で不明選択済みとは扱わない。
- 新BZ予測からの転送は周期を保持し、確認画面にも表示する。選択途中と無効な周期の転送は拒否し、既存カウンターへ書き込まない。
- 先頭一致照合に潜水艇の周期も含める。同じ同乗区分でも周期が違えば自動統合しない。旧未記録と明示した不明も一致扱いにしない。
- 既存の生バックアップ・取消・二重送信防止・旧累計/先頭不一致/別タブ保存の保護を維持。旧データの表示用補完を保存へ書き戻さない。
- 数値計算・なな様テンプレ・画像カードの定義は変更しない。
