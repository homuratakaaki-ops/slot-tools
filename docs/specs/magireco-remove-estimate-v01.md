### 残すもの（取り違えないこと）

- **`certCount(S)`（`:205`）は推測計算ではない。** `bayesExclusions()` の件数合計で、
  カードの `blocks`（`:426`）・サマリー（`:437`・`:442`）・テンプレのヘッダー（`:303`）で

### 共通ファイルは変更不要

設定推測タブは `garei_zero_re` / `magireco` / `milliongod` / `toaru2` の4機種にある。
**magireco の `<script>` タグを外すだけでよい。**

engine はタブ数を nav のボタン数と `pages` の長さで決め、`cardPageIndex` 未指定なら
最終ページをカードタブ扱いにする。**4→3タブで問題ない。**

## 2【必須】`magireco-checker.html`

1. nav から `設定推測` のボタンを削除し、**3ボタン**にする。
   `data-p` を `0,1,2` に振り直す（カードが `data-p="2"` になる）
2. `<style>` の `nav{…grid-template-columns:repeat(4,1fr)…}` を **`repeat(3,1fr)`** に

4. `checker-data/magireco.js` の `?v=` を更新（§9-86。変更したJSの参照のみ）
5. `description` / `og:description` から「**設定推測と**」を外す

```
- …示唆演出をタップで記録し、設定推測と共有カードを作成できます。
+ …示唆演出をタップで記録し、共有カードを作成できます。
```

**ヘッダーの `<small>` に版数表示を足さないこと**（既存チェッカーは持たない。PR #7・#12 と同じ扱い）。

## 3【必須】`checker-data/magireco.js`

### 3-1 削除

- `pages` を `[()=>pageCounts(ctx), ()=>pageSuggest(ctx), pageCard]` にする
- `pageBayes()` 関数ごと削除
- `pageStyle()` 内の `.bayes-main` / `.bayes-bar` のCSS 2行を削除
- `bayesSpec` / `bayesResult` / `bayesPct` / `bayesExcludedSettings` / `bayesUnder4` /
  `bayesExcludeSummary` を削除
- **カードのサマリー右列から `bayesExcludeSummary(S)` を削除**（`:445` の末尾）
- 推測専用に作っていた確率テーブル（`denomProbs` / `EPISODE_PROBS` / `CZ_SOURCE.combined` 等、
  `bayesSpec` からしか参照されていないもの）も削除する。
  **ただし画面のサブラベルやヒントに出ている数値は残す。**
  削除前に「`bayesSpec` 以外から参照されていないこと」を確認すること

### 3-2 名前の整理（夢爽裁可）

- `bayesExclusions` → **`certList`** に改名
- 各要素から推測専用の **`exclude` フィールドを落とす**（`label` と `count` だけにする）
- `certCount` の**値は変えない**（`certList(S)` の `count` 合計）
