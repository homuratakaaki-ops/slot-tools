## 記録の定義：士気高揚ゾーンの小役別ボーナス当選（2026-10-27 シオン指示で確定）

出典（ちょんぼりすた https://chonborista.com/slot/yamasa-slot/263531/ 、2026-10-20 更新・2026-10-26 取得）の
「士気高揚ゾーンの小役揃い時のボーナス期待度」の表の下の文（原文）：

> 士気高揚ゾーン中に小役が揃い、孔明前世へ移行した際のボーナス期待度。高設定ほどボーナスに当選しやすい。なお、下二桁「09」Gでの士気高揚ゾーン当選にも設定差がある模様。

この定義に合わせ、**母数は「小役揃いの回数」ではなく「小役が揃って孔明前世へ移行した回数」** とする。

- 小役が揃って孔明前世へ移行し、ボーナスに当選した → ［当選］（n と d を +1）
- 小役が揃って孔明前世へ移行し、当選せず戻った → ［ハズレ］（d だけ +1）
- 小役が揃っても前世へ移行しなかった → 押さない

画面の説明（通常時タブ）：
「士気高揚ゾーン中に小役が揃って孔明前世（ボーナス前兆）へ移行したとき、ボーナスに当選したら当選、当選せず戻ったらハズレで記録します。小役が揃っても前世へ移行しなかったときは押しません。役ごとに分けて押してください。既存の『突入／なし』とは別の記録です。」
ガイドの説明も同じ定義にした（表は「孔明前世へ移行したときのボーナス期待度」で、小役揃い全体に対する当選率ではない旨を併記）。
確率（設定1〜6）はガイドの表と画面の目安にだけ使い、推定には使わない（推定タブが無いため）。

## 検収項目（ネネ）：実装中に混入し、既存テストで検出・修正した不具合

  青背景・黄背景・期待度UPの4種も同じく確定演出として数えられる。

  これを否定なしの配列と取り違え、保証設定1の確定演出として扱っていた。
