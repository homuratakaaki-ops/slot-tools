## 夢爽の裁定（10/1）

- 日誌の開始日は **2026-09-01**。それより前はパチマガが正。日誌の8月以前の台は消さずに残し、合計に入れない
- 名前（機種・店）をまとめられる。元の記録は書き換えず、日誌の中だけでまとめる
- 機種別の表で、少ない機種（既定3台以下）は「その他」にまとめる
- 機種にお気に入り（★）を付けられる
- 狙い方タグは全機種共通と機種専用の両方、どちらも自分で作れる

## 1. 開始日

- meta `startDate`（既定 "2026-09-01"）。設定で変えられる
- ホーム・履歴・分析の合計は、date が開始日以降の台だけ
- 開始日より前の台は、設定の「開始日より前の記録（n台）」から一覧で見られる。合計には入れない
- 取り込みは今までどおり全部入れる（開始日で弾かない）

## 2. 台を隠す・消す

台の詳細に［隠す］［消す］。

- **隠す**：play.hidden=true。合計・一覧から外れる。設定の「隠した台（n台）」から戻せる
- **消す**：確認のうえ削除。meta `deletedIds` に id を残し、**取り込み直しで復活しない**。設定の「消した台」から取り消せる（id を deletedIds から外すと、次の取り込みで戻る）

## 3. 名前をまとめる（機種・店）

- ストア `aliases`（keyPath:id）：`{id, kind:"machine"|"shop", from, to}`
- 設定 →「名前をまとめる」→［機種］［店］の切り替え。名前の一覧（件数つき・件数順）。複数選んで［まとめる］→ 代表の名前を選ぶ（一覧の中から、または入力）
- **候補の自動表示**：正規化（NFKC・空白と「、・－ー」を除く・英字は小文字）して同じになる名前の組を「まとめる候補」として上に出す。自動ではまとめない。決めるのは夢爽
- 候補には［違う］。押した組は meta `notSameName` に対ごと（A・B・C なら A-B／A-C／B-C）完全一致の名前で残し、二度と候補に出さない。設定から取り消せる（10/1 追加）
- 候補の規則（10/1 夢爽の追加）：比べる前に先頭の種別記号（スマスロ／パチスロ／パチンコ／PA／CR／P／L／S／e）を外す。そのうえで「一致」「語順の入れ替え（文字の集まりが同じ）」「含む（短い方4文字以上）」「先頭一致が短い方の8割以上」のどれかで候補
- まとめた組は一覧で「代表 ← 元の名前（n件）」と表示し、［解除］できる
- 表示・集計・絞り込みは代表の名前で行う。play の machine・shop は書き換えない
- 書き出し・復元に aliases を含める

## 4. その他・お気に入り

- 機種別の表：台数が**しきい値以下**（meta `minorThreshold`、既定 3）の機種を「その他（n機種）」1行にまとめる。押すと中身が開く。合計には入ったまま
- ★：機種別の表の行と、台の詳細の機種名の横に。meta `favorites`（代表の名前の配列）
- ★の機種は「その他」に入れない。分析の機種別の表の一番上に並べる
- ホームに「★の機種（今月）」：機種ごとの台数・合計。★が無ければ出さない

## 5. 日記

- 日の詳細に「その日の日記」（days.diary、自由記述）
- 台の詳細に「その台の日記」（play.diary）＋任意の問い2つ（play.q1「何を狙って、どう判断した？」、play.q2「次に同じ場面ならどうする？」）。空でよい
- 書いたら自動保存（入力が止まって1秒後）。保存したことを小さく表示
- 取り込み直しで消えない（第1段の合流規則のまま）

## 6. 狙い方タグ・自由タグ

- tagDefs：`{id, kind:"aim"|"free", name, scope:"all"|<代表の機種名>}`
- 台の詳細に「狙い方」（1つ選ぶ。候補はその台の機種で使えるもの＝scope が all か、その機種）と「タグ」（複数）。どちらも［＋新しく作る］で scope を選んで作れる
- 「複合」は既定で用意（scope:all）。途中で狙いを変えた台に
- 設定 →「タグの管理」：名前の変更（台にも反映）・削除（台から外す。確認あり）・scope の変更
- 分析に**機種 × 狙い方**の表：機種を選ぶと、狙い方ごとに台数・合計・1台平均・想定期待値の合計。狙い方が無い台は「（なし）」。集計は play.aim だけ（自由タグでは数えない）
- 分析の絞り込みに「狙い方」「タグ」を追加

## 7. note用コピー

台の詳細と日の詳細に［note用にコピー］。押すとプレビューのシート：

```
【9月30日】彼女、お借りします
狙い：リセット100G確認
実戦結果：現金投資 5,000円／貯玉 +2,315枚／収支 +6,123円（1枚 4.8円換算）
節目：
・CZ（赤）→ かのかりBONUS
・1GレンCHANCE 3人攻略
― 日記 ―
（その台の日記。問いに答えていれば「何を狙って…：」の形で続ける）
```

- 日付は月日（曜日なし）。店名・台番号・時刻は**既定で入れない**。シートのトグルで本人が入れられる
- 金額と枚数は分けて書く。換算条件を添える。未換算なら枚・玉のまま
- 節目は第1段の節目（当選・終了・お金・示唆タグ）を最大10行。生ログは入れない
- 日の詳細からは、その日の台を順に並べ、最後にその日の日記
- ［コピーする］でクリップボードへ。自動で投稿・送信はしない

## 8. 同じ台の候補を確認する

- 第1段で数えている「同じ台の候補」（同じ日・店・機種で出どころが違う）を、設定の「同じ台の候補（n組）」で一覧
- 1組ずつ並べて表示（出どころ・金額・時刻）。［同じ台としてまとめる］［別の台］
- まとめる：どちらを正にするかを選ぶ（既定：rec 系＞簡易収支＞遊タイム・マイログ、ただし rec と簡易収支なら収支は簡易収支）。もう一方は mergedFrom へ。解除できる
- 別の台：その組を二度と候補に出さない（meta `notSame` に組を残す）

## 9. 収支の登録・店舗設定（日誌側）

- ホームに［＋収支を登録］。入力は rec の簡易収支と同じ項目（実戦日・種別・機種・店舗・条件・現金投資・現金回収・引出・預入・メモ）。source:"nisshi"
- 設定に「店舗設定」：stores の登録・編集（rec と同じ形）。条件を足したとき「条件なしの収支が n件。適用しますか？」（rec93 と同じ）
- rec の収支帳は第2段では残す（夢爽が日誌での登録に慣れてから、第3段で外す）

## 10. 検証

- 開始日：9/1 にすると8月の台が合計から外れ、「開始日より前」に出る。開始日を変えると合計が変わる
- 隠す・消す：消した台が取り込み直しで復活しない。取り消すと次の取り込みで戻る
- 名前をまとめる：「彼女お借りします」と「彼女、お借りします」が候補に出る → まとめる → 機種別の表で1行（11台・+115,961円）。「高岡DSG」と「DSG高岡」も候補に。解除で元に戻る
- その他：3台以下の機種が「その他」に。しきい値を変えると変わる。★の機種は3台以下でも単独
- 日記：書いて閉じて開き直すと残る。取り込み直しで消えない
- 狙い方：作る→付ける→機種×狙い方の表に出る。名前の変更が台に反映。scope が機種専用のタグは他の機種の台では候補に出ない
- note用コピー：既定で店名・台番号・時刻が無い。トグルで入る。未換算の台は枚のまま
- 同じ台の候補：まとめる・別の台・解除
- 収支の登録：登録した台が今日に出る。店舗設定で条件を足すと適用の確認
- 書き出し → 空のブラウザで復元：aliases・tagDefs・meta（開始日・★・しきい値・deletedIds・notSame）・日記・狙い方がすべて戻る
- 390×844・375×667 で横はみ出し0、タップ44px以上
- rec 系の監査ハーネス・通し操作に変化なし
