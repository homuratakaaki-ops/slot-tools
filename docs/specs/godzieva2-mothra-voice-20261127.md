■ 作業内容
0. この指示書を docs/specs/godzieva2-mothra-voice-20261127.md として保存する。
1. 保存の扱い（ここが一番大事）
   ・新しいグループ mothraG を足す。キーは g44・g55・g66 で、初期値は0。MERGE_KEYS と DEF に追加する。
   ・endVoice に rei と gendo を足す（初期値0）。
   ・既存のキー名と値は変えない。旧データは normalizeState で0を補うだけにする。schemaVersion は上げない。

   ・「ボーナス・AT終了画面」と「終了画面のボイス」の間に新しい節を足す。
     見出し：ゴジエヴァアタック モスラの初期G数
     行：44G「設定4以上濃厚」、55G「設定5以上濃厚」、66G「設定6濃厚」（3行とも目立つ色）
     説明：「ゴジエヴァアタックでモスラが選ばれたとき、初期G数が44G・55G・66Gなら押します。終了画面のモスラとは別の項目です。」
   ・終了画面のボイスの行を、次の順番と説明にする（「示唆内容は調査中」は消す）。
     shinji  シンジ   デフォルト

     mari    マリ     ボーナス間天井250G以内の期待度約66%

     rei     レイ     AT間天井750G以内濃厚
     misato  ミサト   次回ゴジラボーナス濃厚
     gendo   ゲンドウ AT間天井250G以内濃厚
3. 確定演出の集計
   ・CERT に mothraG の3行を足す（ラベルは「モスラ44G」「モスラ55G」「モスラ66G」、ランクは4・5・6）。
   ・終了ボイスは集計に入れない。否定（denialRow）は変えない。

   ・終了ボイスは7行にする。

■ 検証手順（テスト版で行う）
1. 旧データ（mothraG なし、endVoice が5キーの保存）を読み込んだとき、次の2点を満たすこと。
   ・既存の値が全部そのまま残る
   ・新しいキーが0で入る
   知らないキーは消さない。
2. mothraG の3つが各1回、ほかの確定演出が0のとき、次の2点が出ること。
   ・「確定演出 計3回」
   ・「確定演出 モスラ66G(6濃厚) ×1」
3. 終了画面の「モスラ」を数えても、mothraG は変わらないこと。逆に mothraG を数えても、終了画面は変わらないこと。
   設1・3否定の表示も変わらないこと。
4. 終了ボイスを数えても、確定演出の回数が増えないこと。割合の分母が7行の合計になること。
5. 新しい10行（モスラ3行と終了ボイス7行）で、加算と取消ができること。
6. コピー本文を、新しく足した4行を除いて main と比べたとき、差分がないこと。
   値が正しい位置に入ること。「収支帳用コピー（プレーン版）」でも、新しい行が崩れないこと。
7. 390px と 360px で、示唆タブ・詳細カード・ガイドが崩れないこと。
8. 既存の verify とブラウザテストを通すこと。
