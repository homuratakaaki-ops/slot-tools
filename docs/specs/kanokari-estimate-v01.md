### 2.5 丸め補正

行合計が100.0でない行は、**各セルを行合計で割って合計100%に割り戻す**（`rateDist`）。
割るだけなので元が0（−）のセルは0のまま残り、0でないセルの比は出典のまま。
コードは出典の数値をそのまま持ち、割り戻しは計算時に行う（転記値と出典の突き合わせを簡単にするため）。

## 4. 計算

`checker-bayes.js` の `CheckerBayes.estimate` をそのまま使う（とある2と同じ方式。共通ファイルは変更しない）。

- settings 1〜6、事前は均等
- multinomial（`log L = Σ n log p`）
  - RB中のキャラ紹介：`chara.p01〜p15`（既存の回数そのまま）
  - 攻略キャラ初回：`scen.s1〜s4`（既存の回数そのまま。`scen.repeat` は入れない）
  - 終了画面：`screens.*` 7種。**`endCustom==='none'` のときだけ**
  - EDボイス：`edStrong.v01〜v11` だけ。既存 `voice.*` は成立役不明なので入れない
- exclusions（出たら除外。出なかったことでは減点しない）

| 観測 | 除外する設定 |
|---|---|
| 終了画面 赤／紫／銀／金 | 1 ／ 1-3 ／ 1-4 ／ 1-5 |
| キャラ紹介 ⑥ | 1-5 |
| キャラ紹介 ⑦／⑧／⑨／⑩／⑪ | 1 ／ 2 ／ 3 ／ 4 ／ 5 |
| キャラ紹介 ⑫／⑬／⑭／⑮ | 1 ／ 1-2 ／ 1-3 ／ 1-4 |
| センチ 44／55／66 | 1-3 ／ 1-4 ／ 1-5 |
| 枚数 246／456／666／394 | 1,3,5 ／ 1-3 ／ 1-5 ／ 1-5 |
| 同一シナリオ連続 | 1-4 |
| EDボイス v08／v09／v10／v11（`voice` の全回数） | 1 ／ 1-3 ／ 1-4 ／ 1-5 |

- 終了画面の除外は `endCustom` に関係なく行う（濃厚の意味はカスタムで変わらない前提。指示書どおり）
- CZ・初当りの 1/x は計算に入れない（初当りタブの参考値のみ）
- 候補ゼロ（矛盾）は「入力条件を確認してください」。材料ゼロは「判別材料なし」
- **注**：現行の表と除外規則では設定6を外す規則が1つもない（どの表でも設定6の列に0が無い）ため、
  実際の入力で候補ゼロになることは起きない。画面の矛盾表示はテストで推定結果を差し替えて確認している

## 5. 入力と保存

保存キー `kanokari-checker-v1` に項目を足すだけ。既存の回数の意味は変えない。

| キー | 既定 | 内容 |
|---|---|---|
| `endCustom` | `'unknown'` | 店のカスタム：`none`（なし）／`custom`（あり）／`unknown`（不明）。旧データは不明として読む |
| `edRole` | `'other'` | EDボイスの成立役の切替：`strong`（強チャンス目）／`other`（それ以外・不明） |
| `edStrong.v01〜v11` | 0 | 強チャンス目に切り替えて押した回数。`voice` にも同時に加算されるので、その内訳 |

- 終了画面の記録ボタンは `endCustom` に関係なく従来どおり押せる
- EDボイス：切替が強チャンス目のとき、1回の操作で `voice.vNN` と `edStrong.vNN` の両方に加算（engine の `data-bump-many`）。取消・減算も両方まとめて
- 画面の回数・割合・カード・テンプレは従来どおり `voice` のまま
