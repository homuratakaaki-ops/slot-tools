## 保存互換と時系列

- 既存のlampイベントと色キーは保持。旧8色・未知項目を削除しない。
- 新しい4色の入力だけに `timing:'quest-fuku-failure'` を追加。旧イベントにこの印を付け足さない。
- 旧ランプの押下契機は確定できないため、新しく判明した意味を遡及適用しない。従来の記録専用のまま扱う。
- ランプはBZ／福引の回数を進めず、記録時点から次の実BZを示す。失敗結果を入力してからランプを入力する。
- 福引を回数に含める設定で、示唆の後から次のBZまでにさらに福引が挟まる場合は、従来のチッチェと同じ未確認ガードを使い、当該示唆では絞らない。福引失敗の直後に入力した示唆はその後の次回BZを指す。
- 緑・赤は候補を除外する条件だけに使用。色の出現率や任意の確率倍率を作らない。設定1の候補重みは残った候補の間で再計算する。
- 開始不明・表範囲外の従来ガードを維持。設定自体の推測・BZ成功集計・なな様テンプレは変更しない。
- 引き継ぎはtimingを保持する。旧ランプと新ランプの同色を同一記録として先頭一致させず、不一致時は既存記録を変えず停止する。
- 減算モードは従来どおりランプ追加不可。訂正は削除／取消。固定表示や入力フローの全面変更は行わない。
