## 2. 全4機種の共通仕様

### 2.1 器（HTML）

`mogumogu-checker.html` を雛形にする。`<style>` ブロックは**1文字も変えずにコピー**する。
変えるのは次だけ。

- `<title>` / `description` / `og:*` / `canonical` の機種名とURL
- `<header>` の機種名
- ヘッダーのリンクは **`← 機種選択` の1本だけ**。ガイド未作成のため `使い方` リンクは置かない
- `<nav>` のボタン（§2.3）と、それに合わせた `nav{grid-template-columns:repeat(N,1fr)}`
- `<script>` の参照（engine は現行のまま `checker-engine.js?v=20260924`、
  機種データは `checker-data/<id>.js?v=20261004`）と `CheckerEngine.mount(CheckerConfigs.<id>)`

### 2.2 機種データの共通形

- `uiV2:true`（§9-99）。ヘッダーにリセットを置かない（engine が入力タブ最下部に描く）
- `nanaCollab` は §3 の機種別指定どおり
- **設定推測タブは作らない。`checker-bayes.js` は読み込まない**
- **中身のないタブは作らない**（示唆の指定がない機種は示唆タブなし）
  - 確認済み: engine は `<nav>` のボタン数と `pages` 配列の長さで決まり、タブ数の固定前提はない。
    `cardPageIndex` 未指定なら最終ページがカードタブ扱いになる。よって2タブ構成で問題ない
- 「設定L」は全面不使用。利用者が読む文言は「設定推測」「確定演出」で統一する（§9-94）
- 出典表記は engine 既定の `sourceCredit()` に任せ、`sourceUrl` に §1 のURLを入れるだけにする
  （`sourceCreditHtml` は使わない）

### 2.3 タブ構成

| 機種 | nav | pages |
|---|---|---|
| 獣王・パリピ孔明・転生王女 | `入力` / `カード` | `[pageInput, pageCard]` |
| モンハン | `入力` / `示唆` / `カード` | `[pageInput, pageShisa, pageCard]` |

下部タブは最大3つなので §9-67 に収まる。

### 2.4 通常ゲーム数の入力欄（4機種共通・入力タブの先頭）

入力タブの**一番上**に次のセクションを置く。

```html
<section class="sec">
  <div class="sec-h">通常ゲーム数</div>
  <div class="inrow"><label>通常ゲーム数</label>
    <input type="number" inputmode="numeric" id="gIn" value="${g||''}" placeholder="0"></div>
  <div class="hint">連動アプリ等で確認した通常時のゲーム数。メニューの総ゲーム数はAT中を含むため入れない</div>
</section>
```

- `id="gIn"` にすること。engine 側に `S.games` へ書く既存ハンドラがある
- 入力欄の名前は「通常ゲーム数」で固定（§9-100：アプリの画面表記に合わせる）
- 説明は上の1文だけを `.hint` に入れ、**`<details>` を手で組まない**。
  engine の `foldHints()` が §9-97 の規則（全体60字未満は畳まない）で自動処理する。
  上の文は41字なので行内表示のままになる。これが期待動作

### 2.5 1/x 表示（§9-70・§9-100）

分母は `S.games`（通常ゲーム数）のみ。**入力があるときだけ 1/x を出し、空欄なら回数だけ出す。**
出典を1つにするため（§9-84）次のヘルパーをデータ側に置き、画面・カード・テンプレは必ずこれを通す。

```js
function rate(g,c){return (g>0&&c>0)?'1/'+(g/c).toFixed(1):'';}
function rateSuffix(g,c){const r=rate(g,c);return r?` / 現在 ${r}`:'';}   // サブラベル用
function countRate(g,c){const r=rate(g,c);return r?`${c}回 ${r}`:`${c}回`;} // テンプレ・カード用
```

`g` が 0（＝未入力）のとき `rate()` は空文字を返すので、1/x はどこにも出ない。
