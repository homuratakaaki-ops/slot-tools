## 2. 入力タブ

回転数：当選ごとのG（入力欄「当選時のG数」＋「追加」で state.gameLog に積む。「最後の1件を取り消す」で末尾を削除）。表示は累計通常G（合計）／登録件数。
**分母＝当選ごとのG合計（§9-105）。** データカウンターの総回転数・打ち始めG〜現在Gの差は AT 中を含むため使わない（§9-70）。分母0（未登録）の 1/x は「—」。
hint：「当選するたびに、その当選までのG数（ホールのデータカウンターの当選G、または台メニューのAT間G）を入力して追加します。合計が設定推定の分母になります。今まわしている未当選区間のG数は分母に含めません。」
参照タブ「調査中の項目」の先頭に行「液晶・メニューのG数」：「液晶G数は設定変更時と電源OFF→ON時に0Gへ戻ります（電源OFF→ONでは内部状態を引き継ぎます）。メニューのAT間G数も設定変更で0に戻ります。設定推定の分母には使わず、当選ごとのG数の合計を使います。」（液晶G数のリセット条件は出典ページで 2026-10-28 再確認）

| path | 行名 | 表示 |
|---|---|---|
| counts.czWho | CZ フーアーユー | 種別の割合（フーアーユー＋影ノ襲来が母数） |
| counts.czKage | CZ 影ノ襲来 | 同上 |
| counts.czUnknown | 通常CZ（種別不明） | 表示なし（割合の母数に入れない） |
| （表示行） | 通常CZ合計 | 3行の合計と 1/x。目安「設1:1/214.4⇔設6:1/200.3（設定差は小さい）」。押せない |
| counts.at | AT初当り | 1/x。目安「設1:1/364.2⇔設6:1/310.5」 |

- `DENOMS.cz={1:214.4,2:214.1,3:211.7,4:202.5,5:197.2,6:200.3}`、`DENOMS.at={1:364.2,2:356.1,3:345.6,4:322.3,5:313.7,6:310.5}`
- 通常CZ合計は `czTotal()`（種別不明を含む）、種別の割合の母数は `czKnown()`（種別不明を含まない）の1か所ずつ（§9-84）。
- 種別ごとの設定別数値は出典に無いので、種別行は 1/x ではなく割合を出す。
- サガバトルは数えない旨、AT初当りは「セット継続・上位移行・千日戦争の引戻しは数えない」「CZ成功からの自動加算はしない」を hint に書く。
