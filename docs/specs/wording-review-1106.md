# 画面文言の洗い出し：作る側の言葉（夢爽 案A、2026-11-06）

ツール内部の計算の扱いを書いた文（「推定には使いません」「根拠にしません」「確率には使いません」など）を、全機種の画面・ガイドから拾った一覧。**今回は一覧のみで、ファイルは変えていない。**

## 調べた範囲と方法

- 対象：checkers.html から導線のある33機種の `checker-data/<id>.js`（画面・カード・テンプレの文言）と `<id>-guide.html`、`checker-engine.js`（カード・テンプレの共通文言）。導線のない3機種（juuou・myjuggler5・vvv2）は末尾の別表。checker 以外のガイド（ジャグラー等）も末尾の別表。
- 方法：コメント行を除き、文（「。」区切り）ごとに「使いません・使わ・根拠・推定に・推測に・判別に・分母・計算に・反映・割合に使・確定演出には数え」などを含む文を機械的に拾い、1文ずつ目で判定した。`checker-engine.js` には該当なし。
- 行番号は 2026-11-06 時点の main（745283c）。
- 残したもの：入力のしかたの指示（「〜は数えません」「分母に含めません」「記録しません」）、機種の性質の説明（「設定1と2は同じ数値のため判別できない」等）、使う人への助言（「根拠にしすぎず合わせて判断してください」）。末尾の「残す文」に列挙。

## 直したい理由が共通する考え方

案の多くは「〜には使いません」を、使う人から見て**何が起きるか**（「％に反映されます」「記録のみです」「候補から外します」）に言い換えたもの。ただし「％に反映されるか」は利用者に見える動きでもあるので、どこまで画面に書くかは判断が要る（下の「判断に迷う理由」に記した）。

```
## §9-109【画面の文言は使う人の言葉で書く】

画面・ガイド・カード・テンプレに出る文言は、使う人が「何が起きるか」「どう受け取ればよいか」「どう入力すればよいか」を書く。ツール内部の計算の扱い（「推定には使いません」「根拠にしません」など）は画面に書かず、仕様書とコードのコメントに書く。例：×「出ないことを低設定の根拠にしません」→ ○「出現率はホール設定で変わります。」（2026-11-06 夢爽採用）
```

補足案（採るかは判断事項）：「％や候補に反映されるかどうかを書く必要があるときは、『％に反映されます／されません』『候補から外します』のように、使う人に見える表示の動きで書く」。上の B4〜B8・B11〜B13 はこの補足を前提にした案。
