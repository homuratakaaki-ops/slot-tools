## 採用しなかった項目と理由

| 項目 | 理由 |
|---|---|
| ED隠しPUSH（白・青・緑・赤・虹） | 全5色とも示唆内容が調査中（虹も設定6扱いにしない） |
| 百合メーターMAX時の抽選 | 設定2〜6が調査中で設定別数値なし |
| 小役からのCZ抽選 | 通常・高確の条件差のみで設定別数値なし |
| 規定G数による抽選 | 設定別の当選率が未公表 |
| AT終了画面・会話演出 | 次回百合MAX報酬の示唆で、設定判別ではない |
| ステージチェンジ演出 | 前兆・マジアゾーン移行の示唆で、設定判別ではない |
| UIうてな／マジアベーゼのアクション | 成立役・前兆の示唆で、設定判別ではない |
| ボーナス・小役確率の記録 | 全設定共通の公表値（参照タブに表のみ載せる） |
| CZ成功率 | 設定別の成功率が未公表 |

## 確認事項（レビューで判明、未反映）

- **RB構成「2人＋相手チームの1人」の奇偶**：出典A・ネネ資料では「エノルミータ2人＋3人目トレスマジア」＝**偶数**期待度UP＋高設定(強)、「トレスマジア2人＋3人目エノルミータ」＝**奇数**期待度UP＋高設定(強)。本書の3段記録では構成行 eno2＝奇数・tres2＝偶数と固定表示しているため、3人目が「相手チームの1人」のときだけ構成行の奇偶表示が出典と逆になる。期待度UPは記録のみで推定に使わないため計算への影響はない。表示文言の扱いはシオン／ネネの判断待ち。
