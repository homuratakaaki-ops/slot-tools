## 4. 運命盤と報酬待ち

運命盤はリール下で進行し、メインの通常時・前兆・前兆ステージと並行する。成功・失敗だけでメインの状態を変更しない。

| 場面 | 扱い |
|---|---|
| 前兆ではない通常時に成功 | 報酬はすぐ発動 |
| 前兆・前兆ステージ中に成功 | 獲得済み報酬として発動を待つ |
| 報酬待ちのままCZ・ATへ当選 | 通常時に戻るまで獲得済み報酬を持ち越す |
| ミッション失敗 | メインの流れは継続 |
| ミッションが終わる前にCZ・ATへ当選 | 未確認。中断・終了・持ち越しのいずれも自動で決めない |

成功報酬：懸糸傀儡演舞／幕間チャンス／通常AT／機械仕掛けの神。女神を直接の成功報酬として登録しない。

操作合意：成功報酬を「報酬待ち：○○」として表示。実際に発動した時に押すと該当する記録へ進む。当選種別と契機「運命盤」は引き継ぎ、二重入力しない。即発動の場合も同じ操作で進める。

「次回運命盤の報酬を示す情報」と「成功して獲得済みの発動待ち報酬」は別の情報として保持する。

通常時幕間失敗後は進んだ液晶G数を引き継ぐ。

### 入力方法

- 当選時のデータカウンターG数を基本に記録。見逃した数値は未入力を許す。
- 懸糸傀儡演舞は1回終了ごとの合計加算G数を入力。途中の加算は個別入力不要。
- データカウンター・加算記録・液晶と異なる区間の補正が揃えば液晶G数を計算する。単純な無条件の足し算にしない。
- 記録不足なら液晶G数を確定値扱いしない。直接修正可能にする。正確な補正式は実装前に既存処理と照合する。
- 実機でリセットされる時点と、ユーザーが数字を入力する時点は別に定義する。

### 🍉の内訳

通常中／運命盤ミッション中／獲得済み報酬の発動待ち中を別枠で記録する。単純合計を内部的に有効な回数と見せない。

- 女神・劇場ジャッジ中は運命盤用に数えない。
- 幕間中も運命盤用に数えない。通常時・AT後いずれも🍉でATへ進む。
- 運命盤発動時から次回分を数える。運命盤失敗後はミッション中の記録を保持する。
- 規定回数到達時の昇格について、ユーザーは内部処理が未確認と判断。記録と自動推定を分ける。
- 報酬の昇格を実際に確認したら、変更履歴を残し、そこから数え直す。以前の履歴は消さない。
- 「報酬変更」で昇格後の報酬を選ぶ操作を採用。単なる誤入力訂正と区別し、誤入力訂正では回数をリセットしない。
- 報酬待ち中の🍉での昇格は目撃なし。昇格しないと確定した意味ではない。
- 待っていた報酬の発動時、待機中の🍉は履歴に残し、通常中のカウントへ自動加算しない。

### 仮ルールと例外の保留

女神失敗後などの🍉回数・残り回数は、一旦リセット扱い。実機での引き継ぎ可能性と正確な時点は未確認。根拠となった実戦報告は「残り1→CZ→🍉を引いても発動しなかった」。これだけで全CZの挙動を確定しない。

重要な保留：当初の「CZ・ATをまたいだらリセット」という広い仮ルールを、通常時の幕間失敗へ適用するかは未確認。同じ通常時が継続するため、専用の未確認項目とする。この保留のまま仕様案にすることはユーザー合意済み。既定の0化や持ち越しを黙って決めない。

## 9. 次回報酬の情報

女神・劇場ジャッジ・幕間・ATに共通：次回報酬が幕間以上なら引き継ぎ、懸糸傀儡演舞だけは引き継がない。

報酬を引き継ぐことは🍉回数も引き継ぐことを意味しない。内部で報酬別に回数を保持する可能性は未確認。
獲得済み発動待ち報酬は本項と別物。通常時復帰後の発動まで保持する。

## 10. モード確認

以前の「女神・AT突入でモード示唆を一律消去」は廃止。複数回先に関係する示唆があるため、対象範囲と履歴を管理する。

| 内容 | 合意 |
|---|---|
| 示唆の保存 | 終了画面・セリフ名、示唆内容、出た区間を残す。上書きしない |
| 対象期間の起点 | 終了画面直後に始まる通常時を含めて3回・5回等と数える |
| 回数の進行 | 女神・AT当選で1つ進む。強チェリー・運命盤経由も同じ |
| 劇場ジャッジ→女神 | 合わせて1回。二重に進めない |
| 通常時幕間失敗 | 回数は進めず、同じ区間に新しい示唆を追加 |
| 当選結果 | G数・契機・当選種別を事実として保存 |
| 推定モード | 事実と分離。候補・不明を許す。判定条件は別途確認 |
| 表示 | 今の通常時に関係する示唆と、過去の示唆・当選結果 |
| 入力 | 既存の終了画面・セリフ記録から自動追加。二重入力不要 |

複数回先の示唆は、今回の区間が終わっても対象期間内なら現在向け情報として残す。期間終了後も履歴は残す。
CZ終了で新たに得た次区間向けの示唆を、旧区間の終了処理で消してはいけない。
通常A/BはG数傾向のみで断定しない。「CならAT濃厚」から全AT直撃をCと逆算しない。別契機の当選や天井などを区別する。
モードの正確な絞り込み・天国回数の判定基準・途中記録開始時の扱いは未確定。根拠不足で自動判定しない。

## 13. シオンへの依頼と確認シナリオ

この文書をもとに、既存定義・器・保存データとの対応表を作り、変更が必要な箇所を切り分けてほしい。未確認事項への実装上の対応、既存データへの影響、スキーマ互換性は実コードを確認して決定する。現時点で実装・移行・公開は行っていない。

まず次の通し操作で、行き先だけでなく記録の残り方を確認する。

1. 劇場失敗→終了画面なしで女神→女神失敗画面→通常時。モードは1回だけ進む。
2. 前兆中に運命盤成功→前兆から女神→AT→通常時復帰→保留報酬発動。獲得済み報酬を消さない。
3. 通常時幕間失敗→液晶G数を引き継ぐ→モード示唆追加。発動回数は保持。🍉の扱いは未確認項目として残る。
4. AT後幕間失敗→液晶1G。通常時幕間の液晶ルールと混同しない。
5. AT終了画面・ボイス→SHOW TIME→通常AT。上乗せ入力なし、ステージ保持。
6. 激情3回成功→AT終了まで継続→終了画面→一劇。
7. 激情4回目以降から神→失敗→通常AT→終了後一劇。ステージ・一劇権利を保持。
8. 運命盤から神→失敗→通常AT。こちらは開始ステージを新規記録。
9. 一劇成功→上位AT記録へ。極限舞踏の個別入力なし。一劇失敗後の上位引き戻しは別契機。
10. 昇格→🍉区切り直し→取り消し。報酬・内訳・履歴が丸ごと戻る。入力訂正だけでは区切らない。
11. 複数回先のモード示唆→複数区間進行→幕間失敗で示唆追加。旧示唆の対象期間を維持する。

量産への持ち越し：主状態と並行状態、未発動報酬、入口別の戻り先・G数・記録項目、複数区間にまたがる示唆を表せるか確認する。他機種で同じ実機ルールを使うとは限らないため、共通エンジンへからくり2固有のリセット条件を固定しない。
