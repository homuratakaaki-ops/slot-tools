# ハイビリターン30｜機種定義 仕様 v0.2（rec49 実装済み）

作成：2026-09-10（シオン）／ v0.2：2026-09-11
根拠：ちょんぼりすた（2025-07-15更新）＋ 夢爽ヒアリング1回目（10問）＋ 2回目（3問）＋ 実装レビュー
対象：tools/rec の機種定義 hibireturn（器は rec49・749890a）

v0.1→v0.2 の変更：
- 32G中の出入りをG数で自動判定（手動の「32G抜け」ボタンを廃止）
- 天国スルーは自動加算（手動ボタン廃止）
- 打ち始めの状態は「不明／リセット後」のみ。開始実Gが32以下なら自動で32G中
- チェリー・スイカを直押しボタンに。全機種で絵文字＋文字に統一
- REG では「ボーナス揃い」を出さない
- 1グループ必須の選択は選んだ瞬間に記録（器の一般ルール）
- 1G連は「終了→32G中→即BIG（実G1）」のルート。ボーナス中の「1G連告知」で契機を記録
- 隠しハイビスカスはON/OFFトグル
- 終了時にG数を聞かない（askGOnEnd:false）
- リプ継続（3連目〜）を追加
区分：**確認済み**＝ヒアリングで確定 ／ **操作合意**＝ツール上の扱いとして合意 ／ **仮ルール**＝解析からの推測。実戦で直す ／ **未確認**＝自動処理の根拠にしない

---

## 1. 状態の一覧

| 状態 | 種別 | G数 | 中で記録するもの |
|---|---|---|---|
| 通常時 | — | 実Gのみ（液晶なし）**確認済み** | レア役／共通ベル／リプ2連／トップランプ／示唆／メモ |
| ボーナス後32G | 通常時の段階（バッジ「32G中」）**確認済み** | 実G（ボーナス終了で0から） | 通常時と同じ |
| BIG | ボーナス | 止まる | フェザーランプ／隠しハイビスカス／共通ベル／1G連／メモ |
| REG | ボーナス | 止まる | 同上 |

- 液晶Gは無い。器の `lcdG:false`。カウンターは実Gだけを使う **確認済み**
- 3つ目のカウンターは「天国スルー」**確認済み**
- モードは天国・超ハイビのみ記録。超ハイビは示唆が出た時だけ **確認済み**
- 並行状態は持たない。ボーナス高確（トップランプ）は記録だけ **操作合意（要確認）**

## 2. 通常時

### 2-1. 記録するもの

| ボタン | 中身 | 区分 |
|---|---|---|
| レア役 | チェリー／スイカ／共通ベル／リプレイ2連（ハズレ） | 操作合意 |
| トップランプ | フラッシュ1回（高確A示唆）／3回（高確B以上） | 操作合意 |
| 示唆 | ハイビスカスの点灯パターン、SE、隠しハイビスカス（下記の示唆一覧） | 操作合意 |
| 32G抜け | ボーナス後32Gを抜けた。天国スルー+1、バッジ「32G中」を消す | 操作合意 |
| メモ | 自由 | — |

- 共通ベルは設定差あり。通常時とボーナス中を合算して1つのカウンター **仮ルール**
- リプレイ2連でボーナスにならなかった回数も残す（約25%で当選のため） **操作合意**
- チェリー・スイカは高確移行の契機。回数は数えるが規定回数の概念は無い

### 2-2. 天国スルーの数え方 **確認済み**

- 実Gが33になった時点で自動で +1（「32G抜け」をログに残す）
- 32G以内にボーナス当選したら 0
- 32G目の小役で当選したときは天国抜け扱い：+1 して当選。「天国」バッジは付けない
- 1G連の当選は 0 にするが「天国」バッジは付けない（ボーナス中の抽選で天国とは別）
- 通常時（33G以降）の当選では変えない

### 2-3. ボーナス当選

契機 **確認済み**（規定Gは無し。「通常の抽選」と言えるものは契機なしでよい）：
- なし（通常の抽選）／リプレイ2連／レア役／32G目の小役／天井／フリーズ／1G連（ボーナス中から自動）

告知の種類 **確認済み**（3分類。示唆内容を横に小さく表示）：

| 分類 | 選択肢 | 示唆 |
|---|---|---|
| 通常 | 通常点灯 | — |
| プレミアム系（次回天国濃厚） | その他のプレミアム点滅／無音／SPテンパイ音＋BIG | 次回天国濃厚 |
| 超ハイビ系（超ハイビモード濃厚） | 片側だけ高速点滅／SPテンパイ音＋REG／プレミアム点滅＋SPテンパイ音 | 超ハイビ濃厚 |

- 「SPテンパイ音＋BIG」「SPテンパイ音＋REG」は揃いが確定してから分かるので、当選種別（BIG／REG）と組み合わせて自動判定できる。当選時は「SPテンパイ音」だけ選び、種別で示唆を決める **操作合意（案）**
- 「プレミアム点滅＋SPテンパイ音」は解析に示唆内容が無い → 記録のみ **未確認**

揃い **確認済み**：7揃い／ハイビスカス揃い／BAR揃い
- ハイビスカス揃い＝BIG1G連の示唆、BAR揃い＝超ハイビの示唆 **仮ルール（解析の「!?」表記）**

### 2-4. 当選時に自動で起きること

- 32G中の当選 → バッジ「天国」を立てる（2連目以降＝天国滞在と判定）**操作合意（案）**
- 超ハイビ系の告知、BAR揃い、隠しハイビスカスのいずれか → バッジ「超ハイビ」**確認済み（示唆が出た時のみ）**
- 天国スルーを0に（32G中の当選のみ）**仮ルール**
- G数は当選時に触らない。終了時に「今のG数」（既定0）

## 3. ボーナス中

### 3-1. 記録するもの **確認済み（3つ＋1G連）**

| ボタン | 中身 |
|---|---|
| フェザーランプ | 白／青／黄／緑／赤／紫／虹（消化中＝次回モード示唆。虹は初当り時は対象外） |
| 隠しハイビスカス | 点灯（超ハイビ示唆） |
| 共通ベル | 回数（通常時と合算） |
| 1G連 | 押すと今のボーナスを終了扱いにし、次のボーナス（BIG）に入る。契機「1G連」 |
| メモ | 楽曲などはここに |

- 楽曲は分かりにくいのでボタンにしない **確認済み**
- 1G連時の終了画面は通常どおり聞ける（任意）。分からなければ飛ばす **確認済み（夢爽「分からない」→任意）**

### 3-2. ボーナス終了 **確認済み（2つ）**

聞くもの：フェザーランプの色（設定示唆）／隠しハイビスカス（点灯／なし）

| 色 | 示唆 |
|---|---|
| 白 | デフォルト |
| 青 | 奇数UP |
| 黄 | 偶数UP |
| 緑 | 奇数かつ高設定UP |
| 赤 | 偶数かつ高設定UP |
| 紫 | 設定4以上 |
| 虹 | 設定6 |

終了後 → 「32G中」バッジを立てる。実Gは0から。

---

## 4. ボーナス後32G

- 通常時の段階として扱う。バッジ「32G中」。通常時と同じボタンが使える **確認済み**
- 32G以内に当選 → 天国（2-4）
- 32G目に小役で当選 → 契機「32G目の小役」。リプ・ベルなら天国50%以上、レア役なら天国濃厚（解析）→ 記録のみ
- 実Gが33になったら自動で「32G抜け」→ 天国スルー+1、「32G中」「天国」「超ハイビ」のバッジを消す **確認済み**
- 天国中は32G以内に次のボーナス。ループしている間「天国」バッジは残る

## 5. G数とカウンター

| 項目 | 扱い |
|---|---|
| 実G | ボーナス当選時は触らない。終了時に既定0。32Gの判定はこのカウンター |
| 液晶G | 使わない |
| 天国スルー | 2-2 |
| 共通ベル | 通常時＋ボーナス中の合算 |
| チェリー／スイカ／リプ2連 | 回数 |
| 天井 | 実G 999（ハイビモードは1005）。到達時は契機「天井」 |

## 6. 示唆のバッジ

| バッジ | 立つとき | 消えるとき |
|---|---|---|
| 32G中 | ボーナス終了 | 32G抜け、または当選 |
| 天国 | 32G中の当選 | 32G抜け |
| 超ハイビ | 超ハイビ系の示唆（告知／BAR揃い／隠しハイビスカス／片側高速点滅） | 32G抜け **確認済み** |
| 次回天国濃厚 | プレミアム系の告知、ボーナス中フェザーランプ虹（初当り以外）| 次のボーナス当選 **仮ルール** |
| 高確 | トップランプ フラッシュ | 記録のみ。バッジにしない **操作合意（案）** |

## 8. 打ち始めに聞くもの **確認済み**

- 実G（データカウンター）
- 天国スルー回数（分かれば）
- 状態：不明／リセット後（32G中かどうかは実Gで判断。実G≤32 かつリセット後でなければ32G中）
- 前回のボーナス種別（BIG／REG／不明）

## 9. 通し操作（rec49 で全本通過）

1. 通常時 → リプ2連で当選 → BIG（7揃い、通常点灯）→ 終了（白／なし）→ 32G中 → +N で33G → 自動で32G抜け → スルー1
2. 32G中に当選（契機なし、プレミアム点滅）→ 天国バッジ → BIG → 終了 → 32G中（天国のまま）→ 当選 → …→ 32G抜け → 天国消える、スルー0→1
3. BIG中に1G連告知（🍉）→ 終了 → 32G中（0G）→ 自動でBIG（1G、契機：1G連）→ スルー0、天国バッジなし
4. BAR揃いで当選 → 超ハイビバッジ → 32G抜けまで残る
5. 32G目の小役で当選（契機：32G目の小役）→ 天国
6. 天井999で当選（契機：天井）
7. 共通ベルを通常時2回・ボーナス中1回 → カウンター3
8. トップランプ3回 → ログに残る、バッジは出ない
