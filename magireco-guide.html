スマスロ マギアレコード 設定判別カウンターの使い方

小役・初当り・示唆演出を記録し、設定推測で絞り込む専用カウンターです。

ツールの目的

このツールは、スマスロ マギアレコードの設定判別で確認したい項目を、実戦中にタップで累計するための専用カウンターです。AT初当り・弱チェリー・スイカからのCZ当選に加えて、ユニバプレート、キャラ紹介、エンディング中のカード、ストーリーの順番、エピソード選択を記録できます。

本機は弱チェリーの出現率とスイカからのCZ当選率に設定差があり、どちらも全6設定の数値が判明しています。通常時に何度も発生するので、記録を続けるほど推測の精度が上がります。

設定別の数値はツールに組み込んであるので、利用者が数値を用意する必要はありません。記録するだけで推測が動きます。

4つのタブの使い方

画面下部のタブで「入力」「示唆」「設定推測」「カード」を切り替えます。

入力タブ

通常回転数と、AT初当り・ボーナス初当り・弱チェリー・スイカからのCZ当選を記録します。通常回転数は推測の分母になるので、最初に入れてください。入れ方は2通りあり、上のボタンで切り替えます。

  • ユニメモで記録（初期状態）… 公式アプリ『ユニメモ』の通常プレイ数をそのまま入力します。着席時にログインしていれば自分の遊技分だけが集計されます。総プレイ数ではなく通常プレイ数を使ってください。
  • 実機の通常ゲーム数で記録 … 打ち始めた時点と現在の通常ゲーム数を2回確認して入力します。その差があなたの遊技分になります。朝イチから打っている場合は打ち始めを0で構いません。

切り替えても入力した数値は消えないので、途中で変更しても入れ直す必要はありません。

示唆タブ

出た演出を、該当する行または右側の＋ボタンでタップして加算します。ユニバプレートは出たときだけ記録する項目で、BIG終了画面・AT終了画面・キャラ紹介・エンディング中のカード・ストーリーの順番・エピソード選択は発生のたびに必ずどれか1つが選ばれるため、記録すると各行の横に割合が表示されます。

設定推測タブ

入力欄はありません。記録した内容から、設定1〜6それぞれである可能性を%で表示します。

カードタブ

共有カード画像と、テンプレ形式のテキストを生成します。テキストは「テキストをコピー」と「収支帳用にコピー」の2種類があります。詳細カードでは全項目の内訳を確認できます。

入力を間違えたとき

  • ヘッダーの「↩ 取消」で直近の操作を1つ戻せます。
  • ヘッダーの「＋加算」を押すと減算モードに切り替わり、＋ボタンが−ボタンになります。
  • 全部消したいときは、入力タブを一番下までスクロールした「データリセット」から行います。2段階の確認があり、実行後もページを再読み込みしていなければ「↩ 取消」で戻せます。

記録できる項目

タブ記録する内容
入力通常回転数、AT初当り（設定1で1/654.6・設定6で1/416.7）、ボーナス初当り（設定1で1/240.6・設定6で1/184.3）、弱チェリー（設定1で1/60.0・設定6で1/50.0）、スイカからのCZ当選（設定1で20.3%・設定6で33.6%）
示唆ユニバプレート5種、BIG終了画面5種、AT終了画面4種、キャラ紹介4パターン、エンディング中のカード12種、ストーリーの順番9パターン、エピソード選択5種、みたまボーナス「発展」からのAT当選2種
示唆（参照）カウンターを置いていない項目の説明です。魔法少女モード選択率・高確移行率について、扱いを書いてあります。

記録しない場面があります

エピソード選択は、選ばれるエピソードが決まっているルートを数えると設定を読み違えます。黒江チャレンジ経由（必ず黒江）、ドッペルモード当選時（必ずいろは）、フリーズ当選時（必ずうい）は記録しないでください。ツール内のヒントにも同じ案内を入れてあります。

スイカからのCZ当選は全部記録します

スイカが成立したら、CZに入ったかどうかを毎回記録してください。マギアチャレンジ・黒江チャレンジのどちらに入った場合も「当選」です。魔法少女モード「さな」中はスイカのCZ当選率が上がるため、実測はやや高めに出ます。モードを見分けて記録を分ける必要はありません。

キャラ紹介はパターン別のメンバーを載せています

どのパターンかは紹介されたメンバーの並びで判別します。①〜⑨それぞれの並びは、セクションの「説明を見る」の中に1パターン1行で全部書いてあります。⑤は①〜④の逆順、⑨は①〜⑦のいずれかで5人目が小さいキュゥべえになります。

BIG終了画面は記録のみです

キャラが描かれていない画面はデフォルトで、選択した楽曲によって複数のパターンがあります。キャラが描かれた4種（水着・2ndシーズンキービジュアル・1stシーズンキービジュアル・小さいキュゥべえ）は設定示唆パターンとされていますが、示唆の内容が公表されていないため、記録だけを残して設定推測には使いません。

AT終了画面は4種を記録します

ATが終わった時の画面を毎回記録してください。キャラが出ない画面は背景が数種類ありますが、どれも「キャラなし」（デフォルト）として記録します。「マギウスメンバー」は設定3・5・6示唆、「みかづき荘メンバー」は設定2・4・6示唆で、どちらも振り分けの数値が公表されていないため記録のみです。「まどか＆いろは」は設定6確定演出で、これだけは設定推測にも使います。

ストーリーの順番は9パターンにまとめてあります

出典の18通りの並び順を、示唆内容が同じもので9行にまとめています。どの並び順がどの行に当たるかは、各行の下に全部書いてあります。1話または3話スタートは奇数示唆系、2話または4話スタートは偶数示唆系、5話スタートは否定系で、降順が崩れた部分の設定を否定します（5→1なら1否定、5→4→2なら2否定）。全て降順なら設定5以上濃厚です。

当選・ハズレの2ボタンがある行

「スイカからのCZ当選」と「みたまボーナス『発展』からのAT当選」は、当選時に「当選」、外れたときに「ハズレ」を押します。「当選」は発生回数と当選回数を同時に1回ずつ、「ハズレ」は発生回数だけを1回加算します。誤タップを防ぐため、この行は行タップでは加算されません。

設定推測の考え方

記録した内容から、設定1〜6それぞれである可能性を%で表示します。サンプルが少ないうちは6つの数値が近く並びますが、これは絞り込めていないことを正しく表しています。記録が増えるほど差が開きます。

推測に使う項目

  • AT初当りと弱チェリー … どちらも通常回転数を分母にします。
  • スイカからのCZ当選 … スイカの発生回数を分母、CZ当選回数を分子にします。
  • エピソード選択率 … 5種類の選ばれた割合をそのまま使います。特に「黒江」は設定1・2で0.1%、設定5・6で6.3%と差が大きく、1回でも出れば大きく動きます。
  • 確定演出と「設定n否定」 … 該当しない設定を計算から外します。外れた設定は0%と表示されます。

推測に使わない項目

  • ボーナス初当り … AT初当りと連動して動くため、両方を使うと同じ情報を二重に数えてしまいます。表示と記録だけに使います。
  • みたまボーナス「発展」からのAT当選 … 設定差は非常に大きい項目ですが、見た目（青・緑）と内部の報酬レベルが完全には一致しないため、参考記録にとどめています。
  • BIG終了画面 … 設定示唆パターンが存在するとされていますが、示唆の内容が公表されていないため、記録だけにとどめています。
  • AT終了画面の「設定3・5・6示唆」「設定2・4・6示唆」 … 示唆の向きは分かっていても振り分けの数値が公表されていないため、記録のみです。設定6確定演出の「まどか＆いろは」だけは計算に使います。
  • 魔法少女モード選択率・高確移行率 … いずれも設定差がありますが、遊技中に滞在状態を確定できないため、カウンターを置いていません。
  • 奇数設定・偶数設定・高設定期待度UPの示唆 … 示唆の方向は分かっていても振り分けの数値が公表されていないため、記録のみで計算には使いません。

ユニバプレートは確定演出として扱っています

AT終了画面でサブ液晶に出るユニバプレートは、銅で設定2以上、銀で設定3以上、金で設定4以上、花火柄で設定5以上、虹で設定6濃厚として、該当しない設定を計算から外します。

この対応は出典では「管理人予想」として書かれているものですが、ユニバーサル系の機種で共通して使われている仕様のため、本ツールでは確定として扱う判断をしています。プレートが出たのに推測が大きく動かない、という挙動にはなりません。

なお、ホールが任意でプレートを表示できる店長カスタムも搭載されているとされています。実際に出たときだけ記録してください。

隣り合う設定の区別は苦手です

本機は設定1と設定2で数値が近い項目が多く、この2つを分けるのは難しくなります（エピソード選択率だけは差があります）。1つに絞り込むためではなく、「設定4以上か、設定3以下か」を判断する材料として使ってください。画面上部にはこの2つの合計を表示しています。

表示される数値は、入力されたカウントに基づく参考値です。サンプルが少ないほど信頼度は下がります。

出典と注意事項

示唆内容と解析数値の出典は、ちょんぼりすた パチスロ解析様です（BIG終了画面は同サイトの終了画面の記事、AT終了画面は機種ページの画像内の表記）。スイカからのCZ当選率は、出典が「マギアチャレンジ」「黒江チャレンジ」に分けて掲載している数値を合算した値を使っています（出典本文の「さな滞在時はスイカの50%でCZに当選」と同じ数え方です）。解析更新により表記や数値が変わる場合があります。

本ツールは設定判別を補助する記録・集計ツールであり、設定や勝敗を保証するものではありません。記録はご利用の端末のブラウザに保存され、別の端末には引き継がれません。ホールのルールを守り、実戦判断は自己責任で行ってください。
